# 小学生古诗词学习平台 · PD 设计方案

> 版本 v1.0 | 2026-09-21 | 面向一年级小学生

---

## 一、产品定位

**一句话**：让一年级小朋友爱上背古诗的闯关小游戏。

**目标用户**：6-7 岁小学一年级，识字有限，需要拼音辅助，注意力持续时间短（≤5 分钟/次），喜欢即时反馈和成就感。

**核心场景**：
- 睡前家长陪伴朗读（亲子模式）
- 课后自主练习背诵
- 老师布置打卡任务

---

## 二、核心功能（v1）

### 1. 诗词探索（首页）
- 70 首诗以卡片形式呈现
- 每张卡片：诗名 + 作者 + 首句
- 筛选标签：全部 / 唐 / 宋 / 汉乐府
- 已读 / 已背标记（用小星星）
- 顶部：已完成数量 + 激励语

### 2. 诗词详情页
- 大字显示全诗，每字上方标注拼音
- 拼音开关（默认开）
- 朗读模式：逐行高亮（自动或手动翻页）
- 底部：上一首 / 下一首

### 3. 背诵闯关
- 在详情页可进入"背一背"模式
- 全诗隐藏，逐行点击解锁
- 完成后弹出星星庆祝动画
- 本地记录已背状态

## 四、设计系统

### 调色板（宣纸 + 朱砂 + 童趣）

| Token          | 色值      | 用途                      |
|----------------|-----------|---------------------------|
| `--bg`         | `#FFFCF0` | 页面底色，暖调宣纸白       |
| `--surface`    | `#FFF8DC` | 卡片底色，浅米黄           |
| `--ink`        | `#2D1B0E` | 主文字，浓墨深棕           |
| `--ink-light`  | `#7A5C3A` | 次要文字、拼音             |
| `--accent`     | `#D94F2B` | 朱砂红，主强调色（按钮/标签/高亮）|
| `--accent-soft`| `#FDE8E2` | 朱砂浅底，悬停/选中背景   |
| `--gold`       | `#E6A817` | 金色，星星/成就            |
| `--green`      | `#4E9E6B` | 竹青绿，"已背"状态         |
| `--border`     | `#E8DCC8` | 分割线、卡片描边           |

**深色模式**：背景换 `#1A1208`（夜晚书房），文字换 `#F5EDD8`，保持朱砂红 accent 不变。

### 字体

- **诗词标题**：`Ma Shan Zheng`（Google Fonts）—— 毛笔感手写体，孩子觉得"真像古诗"
- **诗词正文**：`Noto Serif SC` —— 宋体衬线，易读，有古味
- **拼音 / UI 文字**：`ZCOOL KuaiLe`（Google Fonts）—— 圆润活泼，适合小朋友
- **数字**：`tabular-nums`

### 字号比例（rem）

```
--text-xs:   0.75rem   拼音
--text-sm:   0.875rem  辅助信息
--text-base: 1rem      正文
--text-lg:   1.25rem   诗句
--text-xl:   1.5rem    诗词小标题
--text-2xl:  2rem      页面大标题
--text-poem: 1.75rem   详情页诗句字号（大！）
```

### 间距节奏

4px 基准格：4 / 8 / 12 / 16 / 24 / 32 / 48

### 卡片 & 圆角

- 卡片圆角：`12px`
- 按钮圆角：`full`（胶囊形）
- 装饰元素：水墨晕染风格阴影 `box-shadow: 0 2px 12px rgba(45,27,14,0.08)`

## 六、交互细节

1. **点击卡片**：轻微弹跳缩放（scale 0.97 → 1.03 → 1.0，100ms）
2. **解锁一行**：从模糊 → 清晰的渐现，同时左侧出现 ✓
3. **全部完成**：星星从上方落下（CSS keyframe），背景短暂金色闪光
4. **拼音切换**：高度从 0 → 正常值的平滑动画（100ms ease）
5. **进度条**：首页顶部，已背数/70，金色填充

## 八、技术选型

- **框架**：React 19 + TypeScript + Vite
- **样式**：纯 CSS Variables（无 Tailwind，保持轻量）
- **路由**：React Router v7
- **状态**：useState + localStorage（无需 Zustand，够用）
- **字体**：Google Fonts（Ma Shan Zheng、Noto Serif SC、ZCOOL KuaiLe）
- **图标**：Lucide React（已在 monorepo 中）
- **数据**：直接 import JSON，无需 API
