> 参与角色：儿童UX专家、教育心理学专家、前端工程师、视觉设计师、家长用户、小学生用户
> 讨论时间：2026-10-15

---

## 一、各角色核心观点

### 🧒 儿童 UX 专家

**最严重问题：孩子模式认知超载**

6-12岁儿童工作记忆容量约为4±1个信息块（成人7±2）。现有「全列表+▓▓▓遮盖」设计存在三重认知任务叠加：
1. 找到当前句（视觉搜索）
2. 解码遮盖范围
3. 尝试记忆提取

这是典型的双任务干扰，必须通过**单句聚焦**解决。

**▓▓▓ 遮盖的心理问题**

视觉上有「被屏蔽/封锁」的压迫感，像被警告而非被帮助。建议改为空格下划线或柔和的模糊效果，暗示「等待填写」而非「禁止访问」。

**家长模式的三事并发**

家长需要同时：听孩子背诵（听觉）→ 在列表定位当前句（视觉搜索）→ 点击小按钮（精细动作）。注意力切割严重。改为单句裁判模式可彻底解决。

**成就感设计三项改进**
1. 结果页显示完整诗句内容，而非「第X句」抽象标签
2. 增加完成仪式动效（灯笼点亮、梅花绽放等中国风元素）
3. 加入历史对比：「上次N颗星 → 这次M颗星」

---

### 🧠 教育心理学专家

**口头背诵 vs 文字填空**

口头背诵激活语音工作记忆+语义网络，比文字填空记忆效果更好（Roediger & Karpicke 2006，提取练习效应）。两种模式互补：家长陪背负责深层提取，孩子模式负责巩固字形。

**最重要发现：全句提示1.5秒自动跳过是错误设计**

- 有意义的记忆编码需要3-5秒
- 自动跳过剥夺孩子的主动控制感
- 「读了但没记住」产生挫败感
- **必须改为孩子主动点「好了，我记住了」才继续**

**提示策略改进**

当前两步提示（首字→全句）缺乏中间层。建议加第三档：**韵律线索**（如节拍数或末字），让孩子在首字不够时再努力一次，避免直接跳到全句。

**首次背诵前应先「看诗」**

认知负荷理论：先决知识不足时，直接提取练习有害无益。首次背一首诗应先整体阅读1-2遍，再进入遮盖模式。

**激励机制：进步感比绝对星级更重要**

「这次比上次少用了1次提示」比3星绝对评级更能持续激励（进步原则，Amabile & Kramer）。鼓励文案应用努力归因，避免能力归因（「真聪明」→固定型思维）。

### 💻 前端工程师

**遮盖方案推荐：CSS blur（方案A）**

```css
.line-text { filter: blur(8px); transition: filter 0.3s ease; }
.line-text.revealed { filter: blur(0); }
```
复杂度1/5，GPU加速，iOS Safari完全支持，零兼容问题。

**家长模式单句推进：CSS transform动画**

用 `translateX` 实现句子切换，无需第三方库。关键注意：进入/退出动画各200ms，流畅不卡顿。

**结果页纯CSS庆祝动画可行**

用CSS变量+keyframes实现30个粒子纸屑，3星时触发，星星用 `cubic-bezier(0.34, 1.56, 0.64, 1)` 弹出效果。

**setTimeout 1.5秒的三个问题**
1. 组件卸载内存泄漏（需useEffect cleanup）
2. 竞态：用户快速点击可能叠加状态转换
3. 认知科学角度更应改为用户主控

**iOS Safari 关键注意点**
- 必须用 `100dvh`（已有）
- `backdrop-filter: blur` 低端机掉帧，不要用
- 触控目标最小 44×44px

### 🎨 视觉设计师

**入口按钮区分方案**

「背一背」（孩子自测）用实心大主按钮，「家长陪背」用描边次按钮。主次层级清晰，不再是两个相同权重的红色胶囊。

**遮盖效果：暗墨色圆角块 > ▓▓▓**

▓▓▓ 过于机械，建议改用 `rgba(24,18,10,0.85)` 圆角矩形（border-radius: 4px），与整体毛笔书法风格更协调。或用 CSS blur 方案，更温和。

**家长模式：大按钮分列卡片底部**

✓✗ 从30px小圆圈 → 44px+全宽大区域按钮。当前句卡片加高亮边框（2px中国红），其余句半透明，视觉焦点明确。

**结果页庆典区**

顶部庆典区占屏幕40%高度，星星逐个弹出（stagger动效），CSS星光粒子散射。3星/2星/1星有不同的背景色调和文案情绪。

**颜色体系（四色卡片色条）**

| 状态 | 色条颜色 | 含义 |
|------|---------|------|
| 无提示通过 | `#2E7D32` 深绿 | 完美 |
| 首字提示 | `#FF8F00` 琥珀 | 良好 |
| 全句提示 | `#E65100` 深橙 | 待加强 |
| 未通过 | `#C62828` 中国红 | 需复习 |

### 👨‍👩‍👧 家长用户

**真实陪背场景**

晚上台灯下，手机握在手里，视线在「孩子的脸」和「手机屏幕」之间反复横跳。背诗是当天作业的一项，时间有压力。

**最大痛点：App让我「盯屏幕」，但好的陪背应该让我「盯孩子」**

- 30px按钮误触率高（手指僵，点击两次）
- 全列表定位当前句：诗句相似时容易找错行
- 孩子背完转向下一句，我还没标完上一句，节奏错开

**家长真正想要的**

- 陪背时：只需要知道「当前是第几句」和「两个大按钮在哪」
- 结果页：能截图发班级群打卡（需要显示孩子名字+诗名+日期）
- 不需要：拼音（家长已会背）、复杂账号体系

**多孩子需求**

本地多孩子切换（不需要登录，存两份数据），是多孩家庭留存的关键。

**三个改进优先级**
1. 家长模式→单句裁判+两个大按钮（半屏分区）
2. 结果页支持截图打卡（显示孩子名+诗名+日期）
3. 本地多孩子切换

### 🧒 小学生用户（9岁）

**背诗最烦的事**

「不知道是什么意思，背起来像背乱码」「妈妈坐旁边盯着，随时要犯错的感觉」「卡住了妈妈叹气，那一刻超级尴尬」

**▓▓▓ 的第一印象**

「有点懵，像遇到了bug，黑格子感觉压迫」→ 空格下划线更容易理解「这里等我填」。

**提示按钮心理**

一个人用时不太丢脸，但按钮写「需要提示」感觉像承认失败。改成「看一眼」更中性。提示后希望有机会「重新背一遍这句」，而不是看了就算。

**结果页感受**

1星：「难受，直接把手机扔开」「妈妈也看到了更难受」

希望看到：
- 3星有动画（星星飞出来）
- 「这次比上次少用了N次提示」→ 进步被看见
- 1星时说「这首诗很难，你很勇敢」→ 降低挫败感
- 显示哪一句没背出来的实际诗文

**让背诗变好玩**
- 解锁诗卡（含插图和诗意）
- 连签灯笼（7天一盏）
- 录音功能
- 升级体系：书童→秀才→举人→进士
- **连签比妈妈催更管用**（多邻国验证的心理机制）

## 二、争议点与决策

### 争议1：全句提示后应自动跳过还是用户主控？

- 前端工程师：1.5秒计时器有内存泄漏和竞态问题
- 教育心理学专家：记忆编码需要3-5秒，自动跳过是认知科学错误
- 小学生：「提示后希望能停留久一点，让我真的记一下」

**决策：改为用户主控。全句提示后显示「好了，背下一句」按钮，孩子主动点击才继续。**

---

### 争议2：孩子模式用全列表还是单句聚焦？

- 儿童UX专家：单句聚焦，减少认知超载
- 教育心理学专家：单任务聚焦符合儿童工作记忆限制
- 小学生：「如果感觉要背很久，我就会拖」→ 单句让任务感变小
- 前端工程师：单句切换动画技术可行，CSS translateX

**决策：改为全屏单句聚焦卡片，顶部进度条（第N句/共M句），上方显示上一句作语境提示。**

---

### 争议3：遮盖效果用什么方式？

- 视觉设计师：暗墨色圆角块，比▓▓▓更协调
- 前端工程师：CSS blur最简单，GPU加速，兼容最好
- 小学生：「空格或横线更容易理解」

**决策：用 CSS blur（filter: blur(8px)）作为主遮盖，视觉上柔和；下方空白区域用细线下划线作提示。两者结合，既有技术优势，又有视觉温度。**

---

### 争议4：家长模式是全列表还是单句裁判？

- 家长：「App让我盯屏幕，但好的陪背应该让我盯孩子」→ 必须大按钮
- 儿童UX专家：全列表定位成本高，误触率高
- 前端工程师：单句切换技术可行
- 视觉设计师：当前句高亮+其余半透明，也可以保留列表但降低干扰

**决策：改为单句裁判模式。全屏显示当前句（大字+拼音），底部左/右各一个大按钮（「✗ 再练练」/ 「✓ 背出来了」），顶部进度条。支持左右滑动手势作为快捷操作。**

---

### 争议5：结果页如何提升成就感？

- 小学生：「3星要有动画，要有声音那种」
- 家长：「要能截图发班级群，需要孩子名+诗名+日期」
- 教育心理学专家：进步对比比绝对星级更有效
- 视觉设计师：庆典区占40%，CSS粒子动效可行

**决策：**
1. 顶部庆典区（约40%），星星stagger弹出，3星触发CSS粒子散射
2. 显示进步对比「比上次少用了N次提示」（首次背则不显示）
3. 每句结果显示完整诗句内容
4. 顶部信息栏加孩子名+诗名+日期（为截图打卡设计）

## 二、仍存在的问题（各角色指出）

### P0 级（必须修复，影响核心功能）

**问题1：孩子模式主次按钮倒置**（儿童UX专家、小学生）
- 现状：「看一眼」（flex:1，更宽）视觉权重 > 「背出来了」（固定宽度）
- 影响：系统性引导孩子多点提示，与SM-2算法激励方向相反
- 修改：「背出来了」改为全宽主按钮（54px，绿色实心），「看一眼」降为次按钮（44px，描边）

**问题2：家长模式无法撤销/修改上一句**（儿童UX专家、家长）
- 现状：标记完一句后无回退，误操作无法纠正
- 影响：家长疲惫状态误触率高，标错污染SM-2算法输入数据，会导致功能弃用
- 修改：两大按钮上方增加小字「← 修改上一句」链接

**问题3：全句提示后「用户主控跳过」未体现**（教育心理学专家）
- 现状：全句显示后只能按「✓ 背出来了」，语义失真
- 影响：「诚信陷阱」——孩子看了答案还要按「背出来了」，引发认知失调
- 修改：全句显示后底部按钮改为「好了，下一句」，语义诚实，由用户主动点击才继续

### P1 级（本轮迭代前必须补充）

**问题4：原型只有3星场景，1星场景未验证**（儿童UX专家、小学生）
- 现状：1星场景是最高风险情绪断点，小学生说「1星时直接把手机扔开」
- 缺失：1星时红色大背景是否加剧焦虑？缺少「再背一次」入口
- 修改：补充1星结果页原型（改暖灰/深蓝背景，温和动效，加「再背一次」按钮）

**问题5：「看一眼」后汉字应自动重新遮盖**（小学生、教育心理学专家）
- 小学生原话：「字出来我就想直接看着它背，要是3秒后自动重新模糊，我才会真的去背」
- 认知科学依据：测试效应（Roediger & Karpicke）——检索尝试本身比再次学习更有效
- 修改：「看一眼」后汉字显示约3秒，再自动淡出重新blur，期间按钮变「好，我记住了」

### P2 级（建议修复，不阻断开发）

**问题6：家长模式已完成句子列表有残留**（儿童UX专家）
- 现状：当前句卡片下方显示已完成句，随句数增加会越来越长，破坏单句聚焦
- 建议：移除已完成句列表，只保留进度条表达进度

**问题7：孩子模式「第2句」信息冗余**（儿童UX专家）
- 导航栏已有「第2句/共4句」，卡片内部又重复标注，纯噪声
- 建议：删除卡片内`s3-card-num`标签

**问题8：上一句语境字号偏小**（儿童UX专家）
- 0.8rem + opacity 0.65，接近可读性边界，近视高发年龄段风险
- 建议：字号改为0.85rem，透明度改为0.75

**问题9：入口按钮主次顺序存在场景错配**（儿童UX专家）
- 现状：「背一背」在上（主按钮），「家长陪背」在下（次按钮）
- 风险：首次接触一首诗的孩子应先家长陪背，当前层级引导孩子直接自测→反复失败→挫败
- 建议：原型标注首次使用时的推荐路径，或根据是否有历史记录动态调整主次

## 三、前端技术评审结论

**CSS 粒子 Bug（需修复）**
- 问题：`overflow: hidden` 的庆典区会裁切 `--tx: 140px` 的粒子，粒子飞到边缘硬消失
- 问题：`@keyframes ptfly` 第0帧 `opacity:1`，delay 期间14个粒子叠在同一点可见（约0.5s）
- 修复：`@keyframes` 加预备帧 `0%{opacity:0} 5%{opacity:1}`；粒子层改为 `overflow:visible` 独立容器

**家长模式单句切换动画**
- 用 React `key` prop 触发节点重建，配合 `card-slide-in` CSS动画（translateY(18px)→0，0.28s）
- 不需要外部动画库，纯 CSS + React 可实现

**孩子模式3状态机**
```typescript
type HintState = 'hidden' | 'first-char' | 'revealed'
// hidden → first-char → revealed（终态）
// first-char 时：只显示首字，其余继续 blur
// revealed 时：全句无 blur，底部按钮变「好了，下一句」
```

**PD 需决策的技术约束**
粒子最大扩散半径：方案A（独立overflow:visible层，粒子可覆盖结果列表区） vs 方案B（缩小到±80px，散射范围更小但不会被裁切）。需PD在原型图中明确标注最大半径值。
