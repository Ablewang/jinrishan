# 产品讨论会议记录

**时间**：2026-09-22  
**议题**：现有产品形态评价 + 下一个核心功能

---

## 一、现有产品形态评价

**PM（产品经理）**

整体方向是对的——专注小学生背古诗这个垂直场景，功能克制。但我有两个担忧：一是没有账号体系，数据存 localStorage，孩子换个设备或清了浏览器进度就没了，这对家长来说是信任危机；二是产品闭环不完整，孩子背完诗之后怎么办？成就页展示了星级，但没有驱动下一次打开的动力，没有"回访钩子"。

**语文老师**

我从教学角度看，背诵方式设计得比较合理——逐字解锁符合"先整体感知，再逐步遮挡"的记忆规律。拼音开关也很实用，一年级刚学拼音的孩子需要，二年级可以关掉挑战自己。

但有一个问题：**光背还不够，理解才是目标**。注释和译文有了，但孩子不会主动去看，老师也没有工具检查孩子有没有真正理解。如果只是机械背诵，和死记硬背没区别。另外，课标对各年级的必背篇目有明确要求，现在 70 首是混在一起的，没有按年级分层，一年级家长看到《长恨歌》会懵。

**家长**

说实话，我最关心三件事：孩子愿不愿意用、我知不知道孩子的进度、有没有家长端。

孩子愿不愿意用——目前背一背的动画挺好看，但激励不够，我家孩子背完三首就去玩别的了，没有"今天还差两首"这种推动感。

进度透明度——成就页是有，但我进去看不懂，哪首背了几颗星，还有多少没背，没有一个直观的汇总。

付费意愿——如果真的能帮孩子在家完成每天背一首的任务，每个月十几块我愿意出，但现在感觉更像个工具，不像个产品。

**儿童心理学家**

6-8 岁的孩子有几个关键特征：注意力持续时间短（单次专注约 10-15 分钟），对即时反馈极其敏感，社交比较动机强（"我比同学背得多"），完成感比过程本身更重要。

现有产品的问题是**激励密度不够**。背完一首诗只有一个星级，中间过程没有小奖励。对 6 岁孩子来说，等背完 20 个字才有反馈太漫长了。另外，每次打开 app 都要自己选诗，没有"今天的任务"这个概念，孩子不知道该干什么，大脑很快就切换到别的事情上了。

**游戏设计师**

我同意心理学家的判断。从游戏设计看，这个产品缺少三个核心机制：

1. **每日任务（Daily Quest）**：每天打开有明确目标，完成有专属奖励，形成习惯回路
2. **进度可视化**：不只是星级，要有"70 首背了 12 首"这种进度条，让孩子看到终点
3. **完成仪式感**：背完一首的庆祝动画太弱，要有更爽的反馈——全屏动画、音效、收藏到"我的诗集"

现在的成就系统是静态展示，不是驱动行为的工具。成就要能解锁东西——比如解锁新的背景主题、新的卡片样式，才有驱动力。

## 二、下一个核心功能讨论

**PM**

我列一下候选功能，大家来讨论优先级：
- A. 每日任务系统
- B. 庆祝完成动画（烟花/撒花）
- C. 年级分层（按一/二年级筛选）
- D. 家长进度看板
- E. 语音朗读

**语文老师**

C（年级分层）对我来说是基础需求，没有这个，我推荐给家长时都不知道该怎么说"让孩子背哪些"。但我承认这是内容配置问题，不是功能问题，工作量不大。

真正影响学习效果的是**理解验证**——背完诗之后能不能做几道简单的题，比如"填空：举头望＿＿，低头思故乡"，或者选一选这首诗描述的是什么季节。这比纯背诵更符合课标要求。

**家长**

我最需要 D（家长看板）。我现在根本不知道孩子昨天背了没有，每次都要问孩子，孩子说背了，我也没法验证。如果有个页面能看到"本周背了 3 首，上周 1 首"，我就安心了。

**儿童心理学家**

我要支持 A（每日任务）。研究表明，7 岁以下儿童的自主学习动力主要来自外部结构，不是内在兴趣。没有每日任务，这个 app 就是偶尔用用的工具，不会形成习惯。每日任务 + 连续打卡天数（streak）是目前最有效的习惯养成机制，Duolingo 就是靠这个的。

**游戏设计师**

B（庆祝动画）是最低成本、最高情绪价值的功能，一两天就能做，但不是最重要的。

我认为优先级应该是：**A（每日任务）> B（庆祝动画）> C（年级分层）> D（家长看板）> E（语音）**

理由：A 解决留存问题，没有留存其他功能都是白费。B 成本低立竿见影。C 是内容配置。D 需要账号体系，工程量大。E 是锦上添花。

**PM 反驳**

我不同意 D 排后面。家长是这个产品的付费决策者，不是孩子。如果家长觉得这个 app 有价值、能监督孩子，才会持续使用甚至付费。没有家长端，产品很难从工具变成产品。但你说得对，D 依赖账号体系，工程量大，短期做不了。

折中方案：先做一个**无需账号的家长分享功能**——孩子背完一首，生成一张带星级的分享图，家长可以发朋友圈，这本身也是社交传播。

**儿童心理学家**

这个折中方案很好。分享图对孩子也有激励作用——"妈妈把我背诗的成绩发朋友圈了"，下次会更努力。

**语文老师**

同意每日任务优先。但我想补充：每日任务的诗应该结合年级推荐，不然一年级孩子被分配到难诗会直接放弃。所以 A 和 C 要配合做。

**游戏设计师（汇总）**

| 优先级 | 功能 | 理由 |
|--------|------|------|
| P0 | 庆祝完成动画 | 成本低，立即提升情绪价值，本周可完成 |
| P1 | 每日任务 + 打卡 streak | 解决留存，形成使用习惯 |
| P1 | 年级分层 | 配合每日任务，内容配置工作 |
| P2 | 完成分享图 | 社交传播 + 家长感知，替代家长看板 |
| P3 | 简单理解题 | 提升教学价值，需要内容制作 |
| P4 | 语音朗读 | 锦上添花 |
| Backlog | 账号体系 + 家长看板 | 工程量大，需要后端支持 |

**全场达成共识。**
