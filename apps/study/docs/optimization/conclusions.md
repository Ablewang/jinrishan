# 产品讨论结论

**日期**：2026-09-22  
**参与角色**：PM、语文老师、家长、儿童心理学家、游戏设计师

---

## 一、现有产品形态评价

### 做得好的
- 背诵机制（逐字解锁）符合认知规律，方向正确
- 拼音开关实用，兼顾不同年级
- 视觉风格统一，儿童友好

### 核心问题
1. **没有回访动力**：缺少每日任务、打卡 streak，用完即走，不形成习惯
2. **激励密度不足**：背完一首只有一个星级，6-8 岁孩子需要更频繁的即时反馈
3. **内容缺乏分层**：70 首混排，没有按年级区分，家长和老师无法引导
4. **家长感知为零**：家长不知道孩子用了没有、背了什么，难以形成付费意愿
5. **数据不持久**：进度存 localStorage，换设备即丢失（长期问题，依赖账号体系）

## 二、下一步功能优先级

| 优先级 | 功能 | 预期价值 | 工作量 |
|--------|------|----------|--------|
| **P0** | **背一背完成庆祝动画**（烟花/撒花） | 提升完成感和情绪价值，立竿见影 | 小 |
| **P1** | **每日任务 + 连续打卡 streak** | 解决留存，养成每日背诗习惯 | 中 |
| **P1** | **年级分层**（一年级 / 二年级 / 全部） | 配合每日任务，降低内容选择门槛 | 小（内容配置） |
| **P2** | **完成分享图**（背完一首生成带星级图片） | 社交传播 + 替代家长看板 | 中 |
| **P3** | **简单理解题**（填空 / 选择，每首 1-2 题） | 提升教学价值，对齐课标要求 | 大（需内容制作） |
| **P4** | **语音朗读** | 辅助认读，锦上添花 | 中 |
| **Backlog** | 账号体系 + 家长看板 | 商业化基础，但工程量大 | 大 |

---

## 三、核心结论

**现阶段最关键的一步：做每日任务系统。**

原因：
- 6-8 岁孩子的学习动力主要来自外部结构，没有每日任务就没有习惯，没有习惯就没有留存
- 每日任务 + 打卡 streak 是目前效果最验证的习惯养成机制（参考 Duolingo）
- 每日任务需要配合年级分层一起做，否则推荐的诗难度不可控

**庆祝动画作为 P0 优先于每日任务完成**，因为成本极低（1-2天），且能立即改善当前用户的完成体验，是在做大功能之前的快速提升。

**家长看板暂不做**，用"完成分享图"作为替代，成本低且能带来社交传播。账号体系列入 Backlog，等产品验证后再投入。
