# 第三轮辩论：要不要 Streak（连续天数）机制？

**辩题**：每日任务是否应该有"连续天数"的 streak 机制？断掉之后怎么处理？  
**发言角色**：小林、陈博士、老李、王妈妈

---

**小林**：

我直接开炮：不做 streak 是在浪费最强的留存工具。Duolingo 靠 streak 把日活留存从 20% 拉到 40%+，这不是玄学，是损失规避的基本心理学。人对"断掉"的痛苦远大于"得到新东西"的快乐。你们担心孩子断了之后有挫败感，但这个挫败感恰恰是驱动他"明天必须回来"的动力。没有 streak，孩子断了三天，心理代价是零，就彻底消失了。陈博士，你说的"累计计数"——"已背 47 首"——那是给大人看的成就感，6 岁孩子根本感受不到数字增长的张力。

---

**陈博士**：

小林，你把 Duolingo 的数据直接套到 6-8 岁身上，这是方法论错误。Duolingo 的核心用户是 18-35 岁的成年人，他们有自我调节能力，能把"断了很痛"转化为"明天补回来"的行动。6 岁孩子遇到 streak 断掉的第一反应是什么？——哭，然后不想再打开。我在临床上见过太多家长来咨询，说孩子因为某个 app 的连续天数断了，直接放弃整件事。你设计的压力机制，对成人是钩子，对低龄儿童是墙。我不反对任何形式的连续性可视化，但 streak 的核心逻辑——"断了就失去了什么"——在这个年龄段是有害的。

---

**老李**：

我站在技术和数据中间说一句。streak 不是非黑即白的——关键是"断了之后怎么处理"。如果断了归零、数字清空，陈博士说的挫败感是真实的。但如果我们做"温柔 streak"：连续天数显示，但断掉之后不归零，改成"本月已完成 X 天"，那么连续感还在，但没有清零的惩罚。实现上完全是 localStorage 的事，复杂度不高。王妈妈，你之前说担心孩子断了会觉得"归零了"——如果断了之后显示"本月完成了 8 天，继续加油！"，而不是"连续天数已重置"，你觉得孩子的反应会不一样吗？

---

**王妈妈**：

老李这个方向我喜欢。说实话，我不是反对"连续"这个概念，我反对的是"归零惩罚"。我家孩子有一次玩某个单词 app，连续 21 天之后有一天忘了，第二天打开看到"连续天数：0"，他在那里哭了十分钟，然后再也不碰那个 app 了。如果能做到——显示连续天数，但断了只是说"继续吧"而不是清零、不是惩罚——我觉得是可以接受的。但我还有一个顾虑：streak 显示在哪里？如果放在首屏最显眼的地方，孩子每天进来第一眼就是"今天必须打卡"，这种压力我不想要。应该做成一个次要的激励，不是主要的焦虑源。

---

**小林（回应）**：

好，我接受老李的"温柔 streak"方案，这是有效的折中。但我要加一个条件：连续天数的视觉展示必须在首屏可见——哪怕不是最大的元素，但必须让孩子每次进来都能看到。如果藏在"我的"页面里，就等于没做。损失规避的前提是让孩子每次看到"我已经连续 X 天了"，这个数字才有情绪价值。我们可以用"温柔"的语言——"已坚持 X 天"而不是"连续 X 天"——断掉后改成"本月坚持了 X 天"，但视觉位置不能妥协。

---

**本轮结论（老李整理）**：

四人达成以下共识：

| 问题 | 结论 |
|------|------|
| 要不要 streak | 要，但做"温柔版" |
| 断掉后是否归零 | 不归零。断掉后显示"本月已完成 X 天" |
| streak 的视觉位置 | 首屏可见，但不是最大的视觉元素，作为次要激励 |
| 文案基调 | "已坚持 X 天"而非"连续 X 天"，断掉用温暖语言提示 |
| 核心驱动力仍是 | 完成任务时的即时视觉爆发（撒花动画），streak 是辅助 |

**遗留分歧**：小林认为连续天数应该在首屏"醒目位置"，陈博士认为应该"次要展示"。两人对"醒目"的定义有分歧，需要在原型阶段用视觉稿验证。
