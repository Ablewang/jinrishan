# 每日任务系统 PRD v2

**版本**：v2.0  
**日期**：2026-10-09  
**基于**：v1 讨论结论 + 用户反馈（待背队列模式替代系统自动推荐）

---

## 1. 核心模型变化

v1 方案是系统按固定顺序每天自动推荐一首诗。v2 改为**家长管理的待背队列**：

| | v1（放弃） | v2（采用） |
|---|---|---|
| 推荐来源 | 系统按难度顺序自动推 | 家长手动往队列里加 |
| 灵活性 | 低，家长无法控制 | 高，老师布置什么就加什么 |
| 适配场景 | 无明确背诵需求时 | 有课本/老师要求时 |
| 队列空了 | 自动循环 | 提示家长去加 |

---

## 2. 核心概念

**待背队列**：家长选好的、待背诵的诗的有序列表，存在 localStorage。队首的诗是今日任务。

**今日状态**：每天只要完成过任意一首背一背，就显示"今天已背诵"。完成后不锁死，允许继续背下一首。

**诗词状态**：每首诗独立维护是否已背过（历史累计），与队列无关。

## 3. 功能详细设计

### 3.1 首页改版

首页新增今日任务卡片，位于进度条下方、诗词列表上方。

#### 状态 A：队列有诗，今日未完成

```
┌─────────────────────────────────────────┐
│  今日待背                                │
│  《静夜思》  唐·李白                     │
│  队列还有 3 首                           │
│                                          │
│  [ 开始背诵 → ]                          │
└─────────────────────────────────────────┘
```

- 诗名大字显示，作者小字
- "队列还有 N 首"让家长对进度有感知
- 点击"开始背诵"直接进入背一背，不经过详情页

#### 状态 B：今日已完成（完成过至少一首）

```
┌─────────────────────────────────────────┐
│  ✓ 今天已背诵                           │
│  《静夜思》 背完了                       │
│                                          │
│  [ 继续背下一首 ]   [ 去看诗词列表 ]     │
└─────────────────────────────────────────┘
```

- 卡片变绿色边框，传达"完成"感
- 提供"继续背下一首"——点击后取队列下一首进入背一背
- 若队列已空，"继续背"按钮变为"去加诗"
- "去看诗词列表"跳转诗词列表页

#### 状态 C：队列为空

```
┌─────────────────────────────────────────┐
│  队列里还没有诗                          │
│  去挑几首，明天就能开始了                │
│                                          │
│  [ 去挑诗 → ]                            │
└─────────────────────────────────────────┘
```

- 卡片用虚线边框，弱提示而非强警告
- 点击"去挑诗"跳转队列管理页

#### 状态 D：久违回访（上次完成距今超过 1 天）

在状态 A 卡片顶部叠加一条温暖横幅：

```
✨ 好久不见，继续出发吧！
```

- 4 秒后自动消失
- 不归零，不惩罚，纯召回

### 3.2 队列管理页

入口：首页顶栏右侧"管理"按钮，或状态 C/B 卡片的"去挑诗/去加诗"按钮。

**页面结构：**

```
┌─────────────────────────────────────────┐
│  ← 返回          待背队列               │
├─────────────────────────────────────────┤
│  当前队列（3 首）           [清空队列]   │
│  ┌──────────────────────────────────┐   │
│  │ = 《静夜思》   唐·李白  [今日]  ✕ │   │
│  │ = 《春晓》     唐·孟浩然        ✕ │   │
│  │ = 《咏鹅》     唐·骆宾王        ✕ │   │
│  └──────────────────────────────────┘   │
│                                          │
│  添加到队列                              │
│  ┌──────────────────────────────────┐   │
│  │ 🔍 搜索诗名或作者...              │   │
│  └──────────────────────────────────┘   │
│  [ 未背诵 ]  [ 已背诵 ]                  │
│                                          │
│  《登鹳雀楼》 唐·王之涣        [ 加入 ] │
│  《相思》    唐·王维           [ 加入 ] │
│  《江南》    汉乐府             [ 加入 ] │
│  ……                                     │
└─────────────────────────────────────────┘
```

**当前队列区：**
- 显示队列中所有诗，按顺序排列
- 第一首标记"今日"标签
- 每首右侧有 ✕ 删除按钮，点击从队列移除
- `=` 拖拽手柄，支持长按拖拽排序（可选，v1 可先不做拖拽）
- 队列为空时显示"还没有诗，从下方选择吧"

**添加到队列区：**

搜索框：
- 支持搜索诗名、作者
- 监听 `compositionstart` / `compositionend` 事件，中文输入法输入期间不触发搜索，输入法确认后再搜索
- 搜索结果实时过滤（防抖 300ms，且跳过 composition 状态）

Tab 分栏：
- **未背诵**：`memorized === false` 的诗，按原始 id 顺序排列（不改变列表顺序）
- **已背诵**：`memorized === true` 的诗，按背诵日期倒序排列（最近背的在前）
- 默认展示"未背诵" tab
- 已在队列中的诗，"加入"按钮变为"已在队列"且禁用，防止重复添加

### 3.3 今日完成逻辑

**完成条件**：当天完成任意一首背一背（三关全过）即算今日已完成。

**完成后流程**：
1. 撒花动画（现有）
2. 将该诗从队列头部移出
3. 标记今日完成（`today_complete = true`，`last_complete_date = today`）
4. `streak_count +1`（同一天不重复计数）
5. 返回庆祝页，显示：

```
《静夜思》背完啦！

床前明月光，疑是地上霜。
举头望明月，低头思故乡。

✨ 背给家长听一遍吧！

[ 继续背下一首 ]   [ 回首页 ]
```

**继续背下一首**：
- 若队列还有诗 → 直接进入下一首的背一背
- 若队列空了 → 提示"今天的诗背完了，去加更多？"，按钮跳转队列管理页

**今日状态显示**：
- 只要 `today_complete === true`，首页卡片就显示状态 B（已完成）
- 状态 B 卡片仍提供"继续背下一首"按钮，不锁死
- 每日 00:00 `today_complete` 重置为 false（跨日检测）

---

### 3.4 Streak 机制

与 v1 一致，温柔版：
- 每天首次完成任意一首 → `streak_count +1`
- 断掉不归零，不惩罚
- 文案"已坚持 N 天"（累计，非连续）
- 断了回来显示"好久不见"横幅，不提断了多久

## 4. 数据结构

```typescript
// localStorage key: 'poem_queue'
interface QueueStore {
  queue: number[]                // 诗的 id 数组，顺序即背诵顺序
  streak_count: number           // 累计坚持天数
  last_complete_date: string | null  // "YYYY-MM-DD"
  today_complete: boolean        // 今日是否已完成，跨日自动重置
}

// localStorage key: 'poem_progress'（现有，不变）
interface PoemProgress {
  [poemId: string]: {
    read: boolean
    memorized: boolean
    bestStars: number
  }
}
```

**初始化：**
```typescript
function loadQueue(): QueueStore {
  try {
    const raw = localStorage.getItem('poem_queue')
    const data: QueueStore = raw ? JSON.parse(raw) : getDefaultQueue()
    // 跨日重置
    if (data.last_complete_date !== getTodayStr()) {
      data.today_complete = false
    }
    return data
  } catch {
    return getDefaultQueue()
  }
}

function getDefaultQueue(): QueueStore {
  return { queue: [], streak_count: 0, last_complete_date: null, today_complete: false }
}
```

**完成一首后写入：**
```typescript
function completePoem(poemId: number) {
  const data = loadQueue()
  // 移出队列头部
  data.queue = data.queue.filter(id => id !== poemId)
  // 今日完成（同一天不重复计数）
  const today = getTodayStr()
  if (!data.today_complete) {
    data.streak_count += 1
    data.last_complete_date = today
    data.today_complete = true
  }
  saveQueue(data)
}
```

## 5. 搜索的中文输入法处理

中文输入法（IME）输入时，`input` 事件会持续触发，但此时用户还没有完成汉字选择，过早搜索会导致搜索结果乱跳。

```typescript
const [isComposing, setIsComposing] = useState(false)
const [inputValue, setInputValue] = useState('')
const [searchQuery, setSearchQuery] = useState('')

// 输入框事件处理
onCompositionStart={() => setIsComposing(true)}
onCompositionEnd={(e) => {
  setIsComposing(false)
  setSearchQuery(e.currentTarget.value)  // 输入法确认后才触发搜索
}}
onChange={(e) => {
  setInputValue(e.target.value)
  if (!isComposing) {
    setSearchQuery(e.target.value)  // 非 IME 输入（英文/拼音直接搜）实时搜索
  }
}}
```

## 7. 验收标准

**队列管理：**
- [ ] 未背诵/已背诵 tab 切换，诗词按正确规则排列，列表原始顺序不变
- [ ] 搜索框中文 IME 输入期间不触发搜索，确认汉字后才过滤
- [ ] 英文/数字输入实时过滤
- [ ] 已在队列的诗"加入"按钮变为"已在队列"且禁用
- [ ] 队列里的诗可以删除，删除后列表刷新
- [ ] 队列第一首标记"今日"

**今日任务卡片：**
- [ ] 队列有诗且今日未完成 → 状态 A（显示队首诗名 + 开始按钮）
- [ ] 今日已完成 → 状态 B（绿色卡片 + 继续背下一首按钮）
- [ ] 队列为空 → 状态 C（去挑诗引导）
- [ ] 久违回访（超过 1 天未完成）→ 状态 A 顶部显示"好久不见"横幅，4 秒消失

**完成流程：**
- [ ] 背一背三关通过 → 撒花 → 庆祝页展示完整诗文
- [ ] 庆祝页"继续背下一首"按钮：队列有诗时可用，队列空时跳转队列管理页
- [ ] 完成后该诗从队列移出
- [ ] 同一天完成多首，streak_count 只 +1

**数据正确性：**
- [ ] 次日打开 app，today_complete 自动重置为 false
- [ ] localStorage 读写失败时 app 不崩溃，静默降级
