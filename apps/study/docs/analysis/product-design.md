# 产品设计分析报告

## 1. 用户体验流程

### 1.1 Onboarding 完全缺失（严重）
新用户打开 App，直接进入空的首页，没有任何引导：
- 不知道什么是"背诗计划"，需要自己去挑诗
- 不知道为什么"学习"按钮是灰色的
- 不知道间隔复习是什么，看不懂进度意义

**建议**：首次打开时，推荐3首适合新手的诗（鹅、静夜思、春晓），一键加入计划，直接开始第一首，完成后解锁下一首。

### 1.2 背诗计划需要主动配置（严重）
用户需要先去"背诗计划"页面手动挑诗，才能在首页看到任务。对小学生和家长来说，这个步骤不够直觉。大部分用户会在这一步流失。

**建议**：App 内置一个默认顺序（按年级/难度），用户可以跟着走，也可以自定义。

### 1.3 复习流程中断后无法续接（中）
复习3首诗，完成2首后关闭 App，下次打开仍需从头开始，没有"继续上次复习"的能力。

---

## 2. 信息架构

### 2.1 底部导航4个 Tab 职责不清晰（中）
- 首页 / 诗集 / 进度 / 我的
- "诗集"和"首页的背诗计划"内容重叠
- "进度"和"我的"信息有交叉（成就在进度页，统计在我的页）

**建议**：重新梳理为：
- 首页（今日任务）/ 诗集（浏览+搜索）/ 我的（进度+成就+设置）

### 2.2 进度页信息密度过高（中）
进度页在一屏内堆叠了：统计数字、进度条、复习统计、成就、已背诗目 + 筛选器，信息层级不清晰，用户容易迷失。

---

## 3. 交互设计问题

### 3.1 背诵模式三轮设计对小学生不够直观（高）
第一轮点击揭示字符、第二轮整行揭示、第三轮选择题，三种交互模式切换时没有清晰的过渡说明，小朋友容易不知道自己在干什么。

**建议**：每轮开始时有一个简短的动画提示（"第1关：找出空缺的字"）。

### 3.2 选择题干扰项生成质量不稳定（中）
干扰项来自其他诗的诗句，有时会出现语义相近的句子导致题目太难，有时干扰项明显不相关导致太容易。

### 3.3 答对/答错反馈时间太短（中）
选择答案后，结果反馈停留时间不足，小朋友还没看清楚就进入下一屏了。

### 3.4 FAB 浮动按钮位置固定在右下，与底部安全区冲突（低）
在部分设备上浮动背诵按钮会被底部导航遮挡。

---

## 4. 视觉设计一致性

### 4.1 CSS-in-JS 与独立 CSS 混用
部分页面用 `<style>` 标签内嵌，部分用 `.css` 文件，导致设计 token（颜色、字体、间距）在两套体系里各自定义，维护时容易不一致。

### 4.2 字体体系不统一
`var(--font-brush)`（毛笔字）和 `var(--font-ui)` 在各页面交替使用，有些标题用毛笔，有些用 UI 字体，没有明确的使用规则。

---

## 5. 儿童适用性

### 5.1 文字反馈语言偏成人化（中）
"间隔复习"、"掌握进度"、"无提示/少量提示"等术语对小学生不友好。建议换成：
- "间隔复习" → "定期复习小测"
- "无提示" → "全部记住了！"
- "掌握进度" → "我背了多少首"

### 5.2 缺少正向激励时机（高）
目前只有背完一首诗后有烟花庆祝，其他时机（首次打开、连续打卡第7天、背完10首）都没有特别反馈。对小学生来说，高频的小奖励比偶尔的大奖励更有效。

### 5.3 家长视角完全缺失（高）
小学生用 App 通常有家长参与。目前没有：
- 家长可查看的学习报告
- 家长设置每日目标
- 学习提醒通知

---

## 优先改进建议

| 优先级 | 问题 | 影响 |
|--------|------|------|
| P0 | 增加 Onboarding 引导流程 | 新用户转化 |
| P0 | 内置默认学习计划 | 降低使用门槛 |
| P1 | 背诵模式每轮给出明确提示 | 小学生理解流程 |
| P1 | 增加更多激励时机 | 用户粘性 |
| P1 | 用词儿童化改造 | 适龄性 |
| P2 | 重构底部导航信息架构 | 整体体验 |
| P2 | 家长模式 | 场景覆盖 |
