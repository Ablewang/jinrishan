## 二、功能需求细化

### 2.1 昵称设置

**目标**：家长给孩子取个名字，分享卡片上显示孩子的名字，让卡片有温度。

**入口**：ProfileSheet 顶部，"小朋友"文字旁边加一个编辑图标（铅笔）。

**交互**：
- 点击铅笔图标或昵称文字，inline 变为 `<input>`，键盘弹起
- 输入框：placeholder "取个名字吧"，maxLength 6，自动 focus，全选已有文字
- 回车或点击输入框外部：保存，恢复为文字展示
- 清空后保存：恢复默认值"小诗人"
- 保存到 `localStorage`，key 为 `poem_nickname`

**校验**：
- 长度 1-6 字符（汉字/英文/数字），超出截断不报错
- 不做特殊字符拦截

**展示**：
- ProfileSheet 顶部：`{nickname}` 大字 + 铅笔图标
- 分享卡片：直接用 `poem_nickname`

#### 2.2.1 今日打卡卡片（现代简约风格）

**视觉方案**（原型评审确认）：

- **整体**：白底卡片，顶部红色色块占 40%，下方白色内容区
- **顶部红色区**：
  - 日期（左上小字）+ App logo（右上）
  - 「今日打卡成功」小标签
  - 昵称大字（ZCOOL KuaiLe，2.8rem，白色）
  - 称号胶囊标签（如「入门学徒」，半透明白底）
  - 装饰：三个不同大小的半透明圆形
- **内容区**：
  - 诗句卡：`#FBF6F0` 背景，左侧红色竖线，显示「今日背了 / 诗名 / 首句」
  - 数据格：两格并排，数字用红色大字（连续打卡天 / 已掌握首）
- **底部**：App 名称 + 口号，细线分隔

**诗名逻辑**：
- 今日 1 首：`《静夜思》` + 首句
- 今日 2 首：`《静夜思》等 2 首`（无首句）
- 今日 3 首及以上：`今日背了 3 首`
- 今日未背：`今日暂无记录` + `明天继续加油！`

**称号规则**（按已掌握首数）：
- 0-4首：诗书初学
- 5-14首：入门学徒
- 15-29首：进阶书生
- 30-49首：饱读诗书
- 50-64首：资深学者
- 65首+：古诗大家

#### 2.2.2 古诗分享卡片

**视觉方案**（原型评审确认）：

- **背景**：该诗配图铺满，叠加 `rgba(0,0,0,0.38)` 半透明黑色遮罩
- **文字**：全部纯白色（`#ffffff`）
- **右上角**：App logo（无边框，直接显示）
- **中心内容**：
  - 诗名大字（书法体，2rem，居中）
  - 分隔线
  - 诗句（书法体 1.45rem，带拼音 ruby/rt，letter-spacing: 0.32em）
  - 作者（小字，`rgba(255,255,255,0.75)`）
- **底部毛玻璃区**：`rgba(0,0,0,0.3)` + blur，品牌名 + 口号
- **高度**：`height: auto`，随诗句行数自适应

**诗句展示**：
- 所有诗句全部显示（不截断），高度自适应
- 拼音用 `<ruby>/<rt>` HTML 标签逐字对齐（Canvas 实现时用 offscreen 计算）
- 超宽诗句：等比缩放整个诗句容器（`scale`，非 `scaleX`）

**分享体验（方案3）**：
```ts
// 先试 canShare，支持就调系统分享；不支持就展示图片让用户长按保存
const file = new File([blob], `古诗-${poemName}.png`, { type: 'image/png' })
if (navigator.canShare?.({ files: [file] })) {
  await navigator.share({ files: [file], title: poemName })
} else {
  // 展示图片，提示长按保存
  showImageForSave(blob)
}
```

### 2.2 分享卡片升级

这是本轮最重要的功能。目标是让卡片真正有内容、有情感，家长看到愿意发朋友圈。

#### 分享卡片类型规划

分享场景分三类，本轮先做前两类：

| 类型 | 触发入口 | 内容重点 | 本轮 |
|------|---------|---------|------|
| **今日打卡卡片** | 首页 / ProfileSheet | 昵称、今日背的诗名首句、连续天数、已掌握数 | ✅ 本轮做 |
| **古诗分享卡片** | 诗集详情页 / 诗集列表长按 | 古诗全文或首联、配该诗插图背景、作者朝代 | ✅ 本轮做 |
| **成就分享卡片** | 成就解锁弹窗内 | 成就勋章、解锁时间、激励文案 | 🔜 后续做 |

两张卡片共用底部品牌区（App logo + 口号），但中间内容区完全不同。路由上用 `type` 参数区分：`/share?type=checkin`（今日打卡）和 `/share?type=poem&id=19`（古诗分享）。

---

#### 2.2.1 今日打卡卡片

**问题**：当前代码：
```ts
const poemText = todayCount === 0
  ? '今日暂无记录'
  : todayCount === 1
    ? `《今日一首》`   // ← 硬编码，没有读实际诗名
    : `今日共背 ${todayCount} 首`
```

`memorizeHistory` 每条记录有 `{ id, stars, date }` 但没有诗名。需要异步加载诗的 index 数据。

**修复方案**：ShareCardPage 加载 `poemIndex`，在 `drawCard` 前等待加载完成，然后：
- 今日 1 首：显示 `《诗名》`（如 `《静夜思》`）
- 今日 2 首：显示 `《静夜思》等 2 首`
- 今日 3 首及以上：显示 `今日背了 3 首`

#### 2.2.2 卡片视觉升级（重点）

当前卡片是纯 Canvas 文字，没有视觉层次，缺乏"值得分享"的设计感。

**目标效果**：像一张精心设计的打卡海报，而不是数据截图。

**升级方向**：

1. **尺寸**：改为 750×1000（竖版），更符合朋友圈图片比例，也方便手机查看。

2. **背景**：不用纯白，用暖米色（`#FFF8F0`）配淡红纹理感（用斜线或网格 pattern）。

3. **顶部大标题区**：
   - 红色圆角卡片区域占上 30%
   - 大字显示昵称（ZCOOL KuaiLe 字体，但 Canvas 字体需要先 load）
   - 下方小字显示称号（如"进阶书生"）

4. **核心数据区**（卡片中部）：
   - 今日背的诗：用书法字体大字显示诗名，加竖排装饰线
   - 连续天数：数字大、标签小，突出视觉重量
   - 已掌握：同样大数字

5. **底部品牌区**：
   - App 名称 + 一句口号（如"每天几分钟，轻松背百首"）
   - 右下角小印章感的"今日山"文字

6. **字体加载**：Canvas 绘制前先用 `document.fonts.ready` 或 `FontFace` 确保字体已加载，否则用 serif 兜底。

### 2.3 成就解锁动画

**目标**：背完一首诗后，如果解锁了新成就，给孩子一个惊喜反馈，增强成就感。

**触发时机**：`markMemorized` 调用后，在 MemorizeMode 的 `onMemorized` 回调里检测。

**动画设计**：
- 全屏半透明黑色遮罩
- 中央一张成就卡弹出（scale 0→1，有弹性曲线）
- 卡片内容：
  - 勋章图标（大，带光晕动画）
  - "新成就解锁！"标题
  - 成就名称（大字）
  - 成就描述
  - 触发原因（如"你无提示背完了《静夜思》"）
- 1.5 秒后自动消失，或点击遮罩关闭
- 多个成就：依次弹出，不叠加

**实现位置**：做成全局组件 `AchievementToast`，挂在 App 根节点，通过 Context 触发。

**检测逻辑**：
- 在 `useAchievements` 里加一个 `checkNewlyUnlocked(prevBadges, nextBadges)` 工具函数
- MemorizeMode 的 `onMemorized` 后对比前后成就状态
- 或者更简单：`useProgress` 的 `markMemorized` 返回一个 `newlyUnlocked` 列表

### 2.4 进度页·本周数据

**目标**：家长打开进度页，能一眼看到"这周学了多少"，而不只是累计数据。

**数据来源**：`memorizeHistory`，每条有 `date`（YYYY-MM-DD）。

**计算方式**：
- 本周一到今天（自然周，周一起算）
- 本周打卡天数：`memorizeHistory` 中本周内有记录的不重复日期数

**展示位置**：进度页顶部统计格，现在是 4 格（已背诵/已掌握/累计字数/连续天数），改为 2 行：
- 第一行：本周打卡 X 天 · 本周背了 X 首
- 第二行：总计 X 首 · 已掌握 X 首 · 连续 X 天

或者在现有 4 格下方加一条"本周"横条。具体布局开发时定，以不拥挤为准。

## 四、分享卡片详细设计

这是本轮最值得打磨的功能，单独展开。

### 4.1 设计原则

家长分享的核心动机是**炫娃**，不是分享 App。卡片要传达：
1. **孩子今天做了什么**（今日成果，具体到诗名）
2. **孩子有多努力**（连续天数，一看就懂）
3. **孩子有多厉害**（总量、称号，给家长虚荣心）

设计上要**像手工制作的打卡卡片**，不像数据报表。

### 4.2 卡片内容结构（750×1000）

```
┌─────────────────────────────────┐
│  [装饰纹理背景，暖米色]           │
│                                  │
│  ┌───────────────────────────┐  │
│  │  [红色圆角区]              │  │
│  │  小明 · 进阶书生           │  │
│  │  2026年10月14日            │  │
│  └───────────────────────────┘  │
│                                  │
│  今日背了                         │
│  ┌───────────────────────────┐  │
│  │  《静夜思》                │  │  ← 大字，书法体
│  │  李白 · 唐                 │  │  ← 小字，作者
│  └───────────────────────────┘  │
│                                  │
│  ┌──────────┐  ┌──────────┐    │
│  │  🔥 7天  │  │ 📚 12首  │    │
│  │  连续打卡 │  │  已掌握  │    │
│  └──────────┘  └──────────┘    │
│                                  │
│          今日山                   │
│   每天几分钟，轻松背百首古诗       │
└─────────────────────────────────┘
```

### 4.3 字体方案

Canvas 不能直接用 CSS 变量里的字体，需要：
```ts
await document.fonts.ready  // 等待页面字体加载完成
// 然后在 ctx.font 里写：
ctx.font = '600 48px "ZCOOL KuaiLe", serif'
ctx.font = '500 28px "Ma Shan Zheng", serif'
```

如果字体未加载（弱网），降级为 serif / sans-serif，卡片仍然可用。

### 4.4 诗首句展示

现有 `poemIndex` 每条有 `firstLine` 字段（来自 `prd-phase2.md` 中的 STARTER_POEMS 结构）。
卡片里今日诗区块可以加一行诗的首句，让看到卡片的人感受到内容：

```
《静夜思》
床前明月光，疑是地上霜。
——李白（唐）
```

这比只有诗名更有分享价值。

### 4.5 保存/分享按钮逻辑

```ts
// 优先级：Share API > 下载链接 > 长按引导
async function handleSave() {
  const blob = await canvasToBlob(canvas)
  const file = new File([blob], `古诗打卡-${nickname}.png`, { type: 'image/png' })
  
  // iOS Safari 支持 share files
  if (navigator.canShare?.({ files: [file] })) {
    await navigator.share({ files: [file], title: `${nickname}今日打卡` })
    return
  }
  
  // Android Chrome / Desktop：触发下载
  const url = URL.createObjectURL(blob)
  const a = document.createElement('a')
  a.href = url; a.download = file.name; a.click()
  URL.revokeObjectURL(url)
}
```
