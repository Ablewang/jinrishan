# 第二期 PRD：Onboarding + 激励体系

**版本**：v0.2（评审修订版）
**状态**：待确认
**目标用户**：小学生（6-12岁）及其家长

---

## 零、术语定义

| 术语 | 定义 |
|------|------|
| 背完一首诗 | 完成第3轮选择题（无论对错率），onMemorized 回调触发即视为背完 |
| 连续打卡 | 按设备本地自然日（00:00-23:59）计算，当日内完成至少1首诗的完整背诵即算打卡一天；连续断开则归零 |
| 无提示通过 | 第3轮选择题全部首次答对（未点击任何"提示一下"按钮，且选择题一次选对所有行）|
| 新用户 | localStorage 中 `poem_onboarding_done` 不为 `'1'` 的用户 |

---

## 一、背景与目标

### 问题
- 新用户打开是空白首页，不知道从哪里开始
- 需要手动配置背诗计划才能看到任务
- 只有背完一首诗才有烟花，其他时机没有激励反馈
- 小学生的家长没有参与感

### 目标
让新用户在首次打开后完成第一首诗，建立正向体验，并通过激励体系驱动持续复访。

**核心指标**（需在版本上线后采集基线再设目标）：
- 新用户完成第一首诗比例 > 70%
- D1 留存 > 50%
- 7日留存 > 30%
- 月均背诗数 / 用户 > 8首

---

## 二、用户旅程

### 2.1 新用户（poem_onboarding_done 不为 '1'）

```
打开 App
  → 欢迎屏（Step 1）
  → 选择入门诗（Step 2，可跳过）
  → 背诗流程（进入现有 PoemDetail → MemorizeMode）
  → 背完 → 庆祝页（Step 3）→ 写入 poem_onboarding_done='1'
  → 进入正常首页
```

**中断恢复**：各步骤状态持久化到 `poem_onboarding_step`（值：0/1/2）。再次打开时从断点继续，而非从头开始。

### 2.2 老用户（poem_onboarding_done 为 '1'）

```
打开 App
  → 直接进入首页（今日任务）
  → 完成背诗 → 检测新成就 → 有新成就则排队弹出动画
```

### 2.3 家长视角

```
任何时候进入"我的"页面
  → 查看本周学习数据（天数 / 已背首数 / 待复习首数）
  → 点击"生成成果卡片"
  → 选择分享或长按保存
```

## 三、功能规格

### 3.1 Onboarding 欢迎流程

**触发条件**：`localStorage.getItem('poem_onboarding_done') !== '1'`

**新增 localStorage key**：
- `poem_onboarding_done`：值 `'1'`，完成 Onboarding Step 3 后写入
- `poem_onboarding_step`：值 `'0'`/`'1'`/`'2'`，用于中断恢复

---

**Step 1 — 欢迎屏**

- 沟通对象：孩子（主），家长（辅）
- 标题："来背一首古诗吧！"
- 副文案："背诗超有趣，跟我一起来！"
- 按钮："开始第一首"
- 右上角：文字链"跳过，自己挑诗 →"（点击后直接进首页，写入 `poem_onboarding_done='1'`，不加入默认计划）

---

**Step 2 — 选择入门诗**

- 展示3张诗卡：咏鹅（骆宾王）、春晓（孟浩然）、静夜思（李白）
- 每张卡片：诗名 + 作者 + 首句 + 难度标签"入门"+ 预估时长"约3-5分钟"
- 说明文案："这3首是入门关卡，选一首开始！"
- **3首在用户点击"开始"时统一加入背诗计划**（而非自动加入，避免污染）
- 卡片可点击切换选中状态，按钮文案跟随变化（"从《咏鹅》开始 →"）
- 右上角：文字链"跳过"

---

**Step 3 — 背完第一首后**

- 触发时机：MemorizeMode 的 onMemorized 回调 + isFirstPoem 标志
- 烟花庆祝动画（现有）
- 大字："你背完了第一首！"
- 副文案："真棒，继续下去你就能背会所有古诗！"（删除"明天记得来复习"，不做无法兑现的通知承诺）
- 按钮："去首页看看 →"
- 此时写入 `poem_onboarding_done='1'`

---

### 3.2 成就勋章系统

> ⚠️ 命名规则：勋章名称与等级称号（3.3节）不得重叠。

**勋章列表**：

| 勋章名 | 触发条件 | 备注 |
|--------|---------|------|
| 初入诗门 | 背完第1首诗 | 原"初出茅庐"，更贴合诗词语境 |
| 三日初成 | 连续打卡3天 | 原"三天打鱼"，三天打鱼是负面成语，必须改 |
| 七日不辍 | 连续打卡7天 | |
| 五首入门 | 背完5首诗 | 原"诗词萌新"，与称号重名，必须改 |
| 十五首晋阶 | 背完15首诗 | 原"小小诗人"，与称号重名，必须改 |
| 三十首精通 | 背完30首诗 | 原"古诗达人"，与称号重名，必须改 |
| 诗书满腹 | 背完全部70首 | 原"诗词状元"，与称号重名，必须改 |
| 过目不忘 | 某首诗第3轮选择题全部首次答对 | 需要 MemorizeMode 增加 hintsUsed 计数器（见技术备注）|
| 铁杆书生 | 连续打卡30天 | |

**展示方式**：
- 进度页成就区域：已解锁彩色 / 未解锁灰色
- 未解锁勋章下方显示进度（如"已背 8/15 首"）
- 新解锁时：全屏弹出动画，展示勋章 + 名称 + 触发的诗名（"你第一次无提示背出了《静夜思》"）
- **多个成就同时解锁**：按固定优先级排队依次弹出，每个动画 0.8 秒后自动消失弹下一个

**技术备注（"过目不忘"）**：
- MemorizeMode 需增加 `hintsUsed` 状态计数器
- 第3轮全部答对且 hintsUsed===0 时，在 onMemorized 回调中传递 `noHintPass: true`
- useProgress 的 PoemState 增加 `noHintPass?: boolean` 字段记录

### 3.4 家长分享卡片

**入口**（持久存在，不依赖当日完成状态）：
- "我的"页面顶部，始终可见
- 完成任务后的 done-banner 上也额外显示一次快捷入口

**卡片内容**：
- 孩子昵称（来自 poem_nickname，默认"小诗人"）
- 当前称号
- 今日背诗：若当日≥1首，显示最后完成的一首；若当日≥2首，显示"今日背了X首"
- 当前连续天数（连续天数=1时，展示"第1天"而非"连续1天"）
- 已掌握古诗总数
- App 名称（固定显示，不含二维码，简化实现）
- 日期

**技术实现**：
- Canvas 生成图片（toBlob）
- 优先使用 Web Share API（`navigator.canShare` 检测）
- 不支持时：将图片显示在全屏预览层，引导"长按图片保存"
- 按钮文案改为"分享 / 保存图片"，不说"一键保存"

### 3.5 昵称设置

**入口**："我的"页面顶部

**规格**：

## 四、不做什么（本期 scope 外）

- 推送通知（"明天记得来复习"类文案须避免）
- 家长独立账号 / 多子女多档案
- 社交互动（排行榜、好友、评论）—— 分享卡片属于内容导出，不属于社交功能
- 云同步（**须在设置页注明：进度保存在本设备，删除App将清空进度**）
- 个性化推荐算法
- 补签卡 / 打卡宽限期
