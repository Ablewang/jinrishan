# 背一背功能方案

## 背景

现有实现问题：所有行同时展示、交互单调、无沉浸感、对一年级学生心理压力过大。

---

## 核心流程：两轮制

### 第一轮「拼音辅助」

- 每次只显示当前一句
- 汉字用红色空心圆圈占位，拼音显示在上方
- 点击每个圆圈 → 爆开动效，露出汉字
- 全句揭示后，底部「背出来了 →」进入下一句
- 所有句通过 → 自动进入第二轮

### 第二轮「完全默写」

- 同样逐句展示
- 拼音也隐藏，只有圆圈，无任何提示
- 所有句通过 → 标记「已背诵」+ 庆祝动画

---

## 交互细节

- 每次只显示当前句，上一句淡出留痕（透明度 20%），后续句子不可见
- 点击圆圈逐字揭示
- 「看答案」按钮：一次全显当前句，不中断进度，但本句不计入「背出」
- 顶部：红色进度条（当前句 / 总句数）+ 轮次标签「第一轮」/「第二轮」
- 每句完成：汉字依次变绿 + 轻弹动效 → 自动滑入下一句
- 背景：当前诗插图全屏铺底 + 深红半透明蒙层

---

## 视觉风格

| 元素 | 规格 |
|------|------|
| 底色 | `#7B1010` 深红 |
| 蒙层 | `rgba(0,0,0,0.5)` |
| 汉字 | `2.4rem`，米白 `#FFF8E1` |
| 占位圆 | 红色描边空心圆，点击爆开 |
| 进度条 | 米白细线，当前句高亮填充 |
| 拼音 | `0.8rem`，半透明米白 |

---

## 完成判定

- 第一轮 + 第二轮全部句子通过 → 标记「已背诵」
- 任一句点了「看答案」→ 该句不计「背出」，但不阻断流程
- 已背诵后再进入「背一背」→ 直接从第二轮开始

---

## 状态机

```
IDLE
  ↓ 进入背一背
ROUND_1（逐句，显示拼音）
  ↓ 所有句完成
ROUND_2（逐句，无提示）
  ↓ 所有句完成
CELEBRATE → 标记已背诵
```
