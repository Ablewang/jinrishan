# T06 · 进度页可视化增强

## 背景

当前进度页是一张静态快照，只回答「我背了多少」，无法回答「我怎么进步的」「哪里最薄弱」「什么时候状态最好」。`recitation_sessions` 和 `review_schedules` 积累了大量高质量数据，但进度页完全没有消费。

## 目标

新增三个可视化模块嵌入进度页：
- M1 学习热力图（12周日历）
- M4 难诗排行 Top5
- M5 最佳学习时段柱图

## 不在范围内

- M2 单诗历程曲线（在 T07 中处理，嵌入详情页）
- M3 逐句薄弱点（在 T07 中处理）
- M6 亲子对比（数据量不足时意义不大，延后）

## 功能需求

### M1 · 学习热力图

位置：四格统计 tiles 下方，总体进度条上方

展示内容：
- 过去12周（84天）日历格，7行（周一到周日）× 12列（周）
- 每格颜色：无背诵=空白，1星总量=淡红，3星=中红，6星+=深红
- 点击某格，弹出当天背诵简报（背了几首，共几星）

实现方式：CSS grid 绘制，无图表库，纯 JS 聚合 `recitation_sessions` 数据

### M4 · 难诗排行 Top5

位置：间隔复习面板下方，成就勋章上方

展示内容：
- 遍历 `review_schedules`，筛选 `totalSessions >= 2`，按 ef 值升序取前5
- 每行：诗名、EF 值、已练次数、颜色标记（ef<1.8=红，1.8–2.2=橙，>2.2=绿）
- 点击跳转到该诗详情页

数据来源：`review_schedules`（T02 完成前用系统B数据估算）

### M5 · 最佳学习时段

位置：难诗排行下方，与 M4 并排（移动端竖排）

展示内容：
- 从 `recitation_sessions.timestamp` 提取小时（0-23）
- 按小时分组，计算平均 qScore 和背诵次数
- 展示频次 ≥ 3 的时段，柱高=平均 qScore，最高柱高亮+标注「最佳时段」
- 仅展示有记录的时段（不显示空时段）

数据来源：`recitation_sessions.timestamp`（需校验历史数据是否有 timestamp 字段）
