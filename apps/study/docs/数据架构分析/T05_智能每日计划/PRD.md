# T05 · 智能每日计划

## 背景

当前用户需手动维护 `poem_queue` 学习队列，孩子不知道今天该背哪首、是否有复习任务。家长每天需要手动选诗加入队列，操作成本高，容易遗忘。

`review_schedules` 和 `poem_review_cards` 已有完整的到期日期数据，完全可以自动生成每日任务，无需用户手动操作。

## 目标

- 自动生成每日学习计划（复习 + 新诗 + 难诗加强）
- 手动队列优先，自动计划兜底
- 首页今日任务展示更清晰

## 不在范围内

- 推送通知（T12 处理）
- 基于 AI 的个性化推荐（远期）

## 功能需求

### 1. buildDailyPlan 算法

新建 `src/lib/dailyPlan.ts`：

```
Step 1 复习优先：
  取 review_schedules 中 nextReviewDate <= today
  按 nextReviewDate 升序排，最多取 3 首

Step 2 新诗：
  poem_queue 中第一首（手动优先）
  若队列为空，取 allPoemIds 中第一首未 memorized 的诗

Step 3 难诗插队：
  review_schedules 中 ef < 1.8 且最近7天内未背过
  按 ef 升序取第一首，插入计划
```

优先级：手动队列 > 难诗插队 > 自动选新诗

### 2. 首页今日任务 UI 改版

当前首页「今日计划」只显示队列第一首诗。改版后展示完整今日任务列表：

- 「今日复习」：到期复习列表（最多3首），每首显示当前档位
- 「今日新诗」：推荐新诗 1 首，来源标注（手动/自动推荐）
- 「攻坚加练」：难诗1首（ef < 1.8 时才出现），显示难度标签

原型图见 → [prototype.md](prototype.md)

### 3. 手动队列入口保留

- 保留原有「管理队列」入口
- 用户手动加入队列的诗优先展示在「今日新诗」位置
- 手动队列为空时自动推荐，有队列时自动推荐不出现

## 验收标准

- [ ] 有到期复习时，首页今日复习区域正确展示对应诗
- [ ] 无手动队列时，自动推荐下一首未背诗
- [ ] ef < 1.8 的诗出现在「攻坚加练」区域
- [ ] 手动加队列的诗优先于自动推荐展示
- [ ] 全部任务完成后展示完成状态
