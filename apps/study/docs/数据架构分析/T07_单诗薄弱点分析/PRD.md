# T07 · 单诗详情页薄弱点分析

## 背景

诗词详情页目前展示静态内容（诗文、注释、译文），无任何历史学习数据。`recitation_sessions` 中有每首诗的逐行结果，完全可以支撑「哪句最难背」「进步曲线如何」的展示，但目前完全没有被消费。

## 目标

在诗词详情页新增「学习记录」tab，展示：
- M3 逐句薄弱点热度条
- M2 单诗背诵历程折线图

## 不在范围内

- 全局难诗排行（T06 处理）
- 复习建议生成（远期）

## 功能需求

### 1. 详情页新增「学习记录」tab

现有 tab 结构（推测）：诗文 / 注释
新增：学习记录（有背诵历史时才显示，否则显示引导文案）

### 2. M3 · 逐句薄弱点

展示该诗所有历次背诵中，每句的：
- 历史通过率（横向热度条，红色越深=越难）
- 平均提示次数（数字）

数据聚合：
- 取该诗所有 `recitation_sessions`
- 按 `lineIndex` 分组
- 通过率 = `passed=true` 次数 / 总次数
- 提示均值 = `hintCount` 之和 / 总次数

少于 2 次背诵记录时，展示「再背一次后可查看薄弱点分析」

### 3. M2 · 单诗背诵历程折线图

展示该诗历次背诵的质量分变化曲线：
- X 轴：第1次、第2次…（按 date 排序）
- Y 轴：qScore（0–5）
- 叠加 passRate 面积填充（半透明红色）
- 右上角展示当前 EF 值及难度标签（轻松/还在练/硬骨头）

SVG 绘制，无第三方图表库，viewBox 自适应点数。

少于 2 次记录时展示：「背诵第 2 次后可查看进步曲线」

原型图见 → [prototype.md](prototype.md)

## 验收标准

- [ ] 有背诵记录时详情页显示「学习记录」tab
- [ ] 无记录时 tab 不显示（或显示引导文案，不显示空图表）
- [ ] 逐句薄弱点颜色与通过率正确映射（高通过率=浅色，低=深红）
- [ ] 折线图点数与背诵次数一致
- [ ] EF 标签正确（≥2.5=轻松，1.8–2.5=还在练，<1.8=硬骨头）
- [ ] 移动端 375px 宽度下图表不溢出
