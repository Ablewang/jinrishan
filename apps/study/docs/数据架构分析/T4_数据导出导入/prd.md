# T4 · 数据导出 / 导入（本地备份）

**类型：** 新功能  
**优先级：** P1  
**估算工时：** 2–3天  
**UI改动：** 设置页新增备份区块；成就弹窗新增备份入口；首页可关闭 Banner

---

## 背景

所有用户数据存于 localStorage，无任何备份机制。iOS Safari 私有模式、WebView、手动清缓存均可导致数据归零。用户背了几十首诗的进度可能一夜清空，严重损害产品信任感。

---

## 需求

### 功能需求

**导出：**
1. 将全部12个核心 key 序列化为 JSON 文件下载
2. 文件名格式：`古诗学习备份_2024-12-15.json`
3. `recitation_sessions` 只导出近90天数据，防止文件过大
4. 附带 FNV-32a checksum 用于导入校验
5. 导出完成后写入 `poem_last_backup_date`

**导入：**
1. 支持两种模式：合并（默认）/ 完全替换
2. 合并模式：`poem_progress` 取两份数据的并集（bestStars 取较大值）
3. 导入前校验 checksum，损坏文件拒绝导入并提示
4. 导入完成后刷新页面使数据生效

**备份提醒：**
1. 距上次备份 > 7天且已背 ≥ 3首，首页顶部展示可关闭 Banner
2. 背完第 5/15/30 首时，成就弹窗下方追加备份入口
3. 同一 session 内 Banner 关闭后不再出现（sessionStorage 记录）

### 非功能需求

- 导出纯前端实现，无需网络请求
- 导入解析失败时展示明确错误信息，不修改任何现有数据

## 界面设计要点

**设置页备份区块：**
```
┌─────────────────────────────────────┐
│  数据备份                             │
│  上次备份：2024-12-08（7天前）         │
│                                       │
│  [导出备份文件]    [从文件恢复]         │
│                                       │
│  存储用量：███░░░░ 1.2MB / 5MB        │
└─────────────────────────────────────┘
```

**首页 Banner：**
```
┌─────────────────────────────────────┐
│ ⚠ 已背 12首诗，建议导出备份保存进度  [备份] [✕] │
└─────────────────────────────────────┘
```

---

## 验收标准

- [ ] 点击"导出备份文件"，浏览器下载 JSON 文件
- [ ] 导出文件包含所有核心 key 数据和正确的 checksum
- [ ] 导入损坏文件时，提示"文件校验失败"，原数据不变
- [ ] 合并导入后，已背诗的 bestStars 取两份数据较大值
- [ ] 距上次备份 > 7天时，首页顶部显示 Banner
- [ ] Banner 关闭后刷新页面不再出现（当次 session 内）
