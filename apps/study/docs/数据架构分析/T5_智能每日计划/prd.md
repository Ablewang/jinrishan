# T5 · 智能每日计划（自动排今日任务）

**类型：** 新功能  
**优先级：** P1  
**估算工时：** 1–2天  
**UI改动：** 首页今日任务区块展示逻辑调整

---

## 背景

当前首页"今日计划"依赖用户手动维护 `poem_queue`，家长每天需要决定"今天背哪首"。对于已有复习积累的用户，系统其实已经知道"今天该做什么"，但没有自动呈现出来。

---

## 需求

### 算法逻辑

新建 `src/lib/dailyPlan.ts`，`buildDailyPlan()` 按以下优先级组合今日任务：

1. **复习优先**：`poem_review_cards` 中 `due <= today && level < 5`，按 due 升序，最多取3首
2. **新诗**：`poem_queue` 队列第一首；若队列为空，按 id 升序取第一首未背过的诗
3. **难诗加强**：`review_schedules` 中 ef < 1.8 且最近7天内未背过，最多1首

**手动队列优先**：用户手动设置的 `poem_queue` 始终作为新诗来源，不被覆盖。

### 功能需求

1. 首页今日任务区，若 `poem_queue` 为空，自动展示 `buildDailyPlan()` 推荐的复习+新诗任务
2. 用户手动加入队列后，显示手动队列（现有逻辑不变）
3. 自动计划与手动队列的切换无需用户操作，根据 `poem_queue` 是否为空自动判断

### 非功能需求

- `buildDailyPlan` 是纯函数，输入固定则输出固定，无副作用
- 不新增任何 localStorage key

## 界面设计要点

**自动计划状态（poem_queue 为空时）：**
```
┌─────────────────────────────────────┐
│  今日计划   智能推荐                  │
│─────────────────────────────────────│
│  复习  《静夜思》    今日到期    [开始] │
│  复习  《春晓》      今日到期    [开始] │
│  新学  《登鹳雀楼》  第1次       [开始] │
│  攻坚  《将进酒》    EF偏低      [开始] │
└─────────────────────────────────────┘
```

**手动队列状态（现有样式不变，只在空队列时降级到自动计划）。**

---

## 验收标准

- [ ] `poem_queue` 为空时，首页展示自动推荐任务
- [ ] 自动推荐优先展示到期复习，其次新诗，最后难诗
- [ ] 难诗加强只在 ef < 1.8 且近7天未背时出现
- [ ] 用户手动加入队列后，切回手动模式，自动推荐不再展示
- [ ] `buildDailyPlan` 单元测试通过（边界：无复习、无新诗、无难诗）
