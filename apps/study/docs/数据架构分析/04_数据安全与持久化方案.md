# 古诗学习 App 数据安全与持久化方案

## 一、当前数据风险完整评估

**核心问题：** 所有用户数据存储在单一 localStorage，无任何备份机制。iOS Safari 私有模式、WebView 环境、手动清除浏览器数据，均会导致全部学习记录瞬间归零。

### 12 个 Key 的丢失代价

| Key | 数据内容 | 预估体积 | 增长模式 | 丢失代价 | 风险 |
|---|---|---|---|---|---|
| `poem_progress` | read/memorized/bestStars/noHintPass | 2–8 KB | 有上限（70首） | 所有学习进度清零，最核心数据 | 极高 |
| `poem_review_cards` | 间隔复习档位、due日期、passCount | 3–6 KB | 有上限（70条） | 复习计划归零，需重新背完才能恢复 | 极高 |
| `recitation_sessions` | 每次背诵完整逐句评分 | 0.5–2 KB/条，**无上限** | 持续增长 ⚠ | 历史详情丢失；更大威胁是容量炸弹 | 高（容量风险） |
| `review_schedules` | 按 poemId 索引的复习调度表 | 2–5 KB | 有上限（70项） | 复习时间表丢失，调度算法失效 | 极高 |
| `poem_streak` | 连续打卡天数 + 最后打卡日期 | <100 B | 固定 | 连续天数归零，影响成就解锁 | 中 |
| `poem_queue` | 今日学习队列 + 队列连续天数 | <500 B | 固定 | 今日队列清空，连续天数归零 | 中 |
| `poem_total_chars` | 累计背诵总字数 | <50 B | 固定 | 累计字数统计丢失 | 中 |
| `poem_memorize_history` | 最近20条背诵记录 | <1 KB | 有上限（20条） | 近期历史清空，影响首页展示 | 中 |
| `poem_achievement_dates` | 9枚勋章解锁时间戳 | <500 B | 有上限（9条） | 解锁时间丢失，成就可从 progress 重算 | 中 |
| `poem_onboarding_done` | 是否完成引导 | <20 B | 固定 | 重新触发引导流程 | 低 |
| `poem_nickname` | 用户昵称 | <100 B | 固定 | 昵称丢失，需重新输入 | 低 |
| `reminder_time` | 学习提醒时间设置 | <50 B | 固定 | 提醒设置丢失 | 低 |

### 容量炸弹分析

`recitation_sessions` 是唯一无界增长项。活跃用户每天背3首诗，一年内该 key 将达到 500–2000 KB。**最危险的问题**：`useRecitation.ts` 中 `saveSessions` 的 catch 块为空，`QuotaExceededError` 会被静默吞掉，导致所有后续写入失败而用户毫无感知。

### 导出实现

```typescript
// src/lib/backup.ts

const BACKUP_KEYS = [
  'poem_progress', 'poem_review_cards', 'recitation_sessions',
  'review_schedules', 'poem_streak', 'poem_queue',
  'poem_total_chars', 'poem_memorize_history', 'poem_achievement_dates',
  'poem_onboarding_done', 'poem_nickname', 'reminder_time',
] as const

function fnv32a(str: string): string {
  let hash = 0x811c9dc5
  for (let i = 0; i < str.length; i++) {
    hash ^= str.charCodeAt(i)
    hash = (hash * 0x01000193) >>> 0
  }
  return hash.toString(16).padStart(8, '0')
}

export function exportBackup(): string {
  const data: Record<string, unknown> = {}

  for (const key of BACKUP_KEYS) {
    const raw = localStorage.getItem(key)
    if (raw !== null) {
      try {
        if (key === 'recitation_sessions') {
          const sessions = JSON.parse(raw) as Array<{ date: string }>
          const cutoff = new Date()
          cutoff.setDate(cutoff.getDate() - 90)
          const cutoffStr = cutoff.toISOString().slice(0, 10)
          data[key] = sessions.filter(s => s.date >= cutoffStr)
        } else {
          data[key] = JSON.parse(raw)
        }
      } catch {
        data[key] = raw
      }
    }
  }

  const dataStr = JSON.stringify(data)
  return JSON.stringify({
    version: '1',
    exportedAt: new Date().toISOString(),
    appVersion: import.meta.env.VITE_APP_VERSION ?? 'unknown',
    checksum: fnv32a(dataStr),
    data,
  }, null, 2)
}

export function downloadBackup(): void {
  const json = exportBackup()
  const date = new Date().toISOString().slice(0, 10)
  const blob = new Blob([json], { type: 'application/json' })
  const url = URL.createObjectURL(blob)
  const a = document.createElement('a')
  a.href = url
  a.download = `古诗学习备份_${date}.json`
  a.click()
  URL.revokeObjectURL(url)
  localStorage.setItem('poem_last_backup_date', date)
}
```

### 导入恢复实现

```typescript
export function importBackup(
  json: string,
  mode: 'merge' | 'replace' = 'merge'
): { ok: boolean; error?: string; stats?: string } {
  let backup: BackupFile
  try {
    backup = JSON.parse(json)
  } catch {
    return { ok: false, error: '文件格式错误，不是有效的 JSON' }
  }

  if (!backup.version || !backup.data)
    return { ok: false, error: '不是有效的古诗学习备份文件' }
  if (backup.version !== '1')
    return { ok: false, error: `备份版本 ${backup.version} 不受支持` }

  const dataStr = JSON.stringify(backup.data)
  if (backup.checksum !== fnv32a(dataStr))
    return { ok: false, error: '文件校验失败，备份文件可能已损坏' }

  if (mode === 'replace') {
    BACKUP_KEYS.forEach(k => localStorage.removeItem(k))
  }

  let restored = 0
  for (const [key, value] of Object.entries(backup.data)) {
    if (!BACKUP_KEYS.includes(key as any)) continue

    if (mode === 'merge' && key === 'poem_progress') {
      const existing = JSON.parse(localStorage.getItem(key) ?? '{}')
      const incoming = value as Record<string, any>
      const merged = { ...existing }
      for (const [id, state] of Object.entries(incoming)) {
        const ex = existing[id]
        merged[id] = ex ? {
          ...ex,
          read: ex.read || state.read,
          memorized: ex.memorized || state.memorized,
          bestStars: Math.max(ex.bestStars ?? 0, state.bestStars ?? 0),
          noHintPass: ex.noHintPass || state.noHintPass,
        } : state
      }
      localStorage.setItem(key, JSON.stringify(merged))
      restored++
      continue
    }

    localStorage.setItem(key, typeof value === 'string' ? value : JSON.stringify(value))
    restored++
  }

  return { ok: true, stats: `已恢复 ${restored} 项数据，来自 ${backup.exportedAt.slice(0, 10)}` }
}
```

## 三、localStorage 容量管理方案（P1）

### 容量监控

```typescript
// src/lib/storageMonitor.ts

export function getStorageReport(): StorageReport {
  let usedBytes = 0
  const keyBreakdown: { key: string; bytes: number }[] = []

  for (let i = 0; i < localStorage.length; i++) {
    const k = localStorage.key(i)!
    const v = localStorage.getItem(k)!
    const bytes = (k.length + v.length) * 2
    usedBytes += bytes
    keyBreakdown.push({ key: k, bytes })
  }

  keyBreakdown.sort((a, b) => b.bytes - a.bytes)
  const totalBytes = 5 * 1024 * 1024
  const usagePercent = usedBytes / totalBytes * 100

  return {
    usedBytes, totalBytes, usagePercent,
    keyBreakdown,
    isNearFull: usagePercent > 70,
    isCritical: usagePercent > 90,
  }
}

export function pruneOldSessions(keepDays = 60): number {
  const raw = localStorage.getItem('recitation_sessions')
  if (!raw) return 0
  try {
    const sessions = JSON.parse(raw) as Array<{ date: string }>
    const cutoff = new Date()
    cutoff.setDate(cutoff.getDate() - keepDays)
    const cutoffStr = cutoff.toISOString().slice(0, 10)
    const pruned = sessions.filter(s => s.date >= cutoffStr)
    const removed = sessions.length - pruned.length
    if (removed > 0) localStorage.setItem('recitation_sessions', JSON.stringify(pruned))
    return removed
  } catch { return 0 }
}
```

### 修复 saveSessions 的静默失败（最高优先）

```typescript
function saveSessions(sessions: RecitationSession[]): void {
  try {
    localStorage.setItem('recitation_sessions', JSON.stringify(sessions))
  } catch (e) {
    if (e instanceof DOMException && (
      e.name === 'QuotaExceededError' ||
      e.name === 'NS_ERROR_DOM_QUOTA_REACHED'
    )) {
      pruneOldSessions(60)
      try {
        localStorage.setItem('recitation_sessions', JSON.stringify(sessions))
      } catch {
        console.error('[Storage] sessions write failed after pruning')
        window.dispatchEvent(new CustomEvent('storage-critical'))
      }
    }
  }
}
```

**清理策略：**
- App 启动时自动清理：若 `recitation_sessions` 超过200条，删除90天前记录
- 使用率超过70%时显示黄色预警
- 使用率超过90%时显示红色警告并推荐立即导出

## 四、IndexedDB 冗余备份方案（P2）

用 IndexedDB 作为 localStorage 的冗余副本。IndexedDB 配额更宽松（通常可达磁盘空间20%），在 iOS Safari 上比 localStorage 更难被意外清除。

```typescript
// src/lib/idbMirror.ts

const DB_NAME = 'poem-backup'
const STORE_NAME = 'kv'

let db: IDBDatabase | null = null

async function openDB(): Promise<IDBDatabase> {
  if (db) return db
  return new Promise((resolve, reject) => {
    const req = indexedDB.open(DB_NAME, 1)
    req.onupgradeneeded = () => req.result.createObjectStore(STORE_NAME)
    req.onsuccess = () => { db = req.result; resolve(db) }
    req.onerror = () => reject(req.error)
  })
}

export async function idbSet(key: string, value: string): Promise<void> {
  try {
    const d = await openDB()
    const tx = d.transaction(STORE_NAME, 'readwrite')
    tx.objectStore(STORE_NAME).put(value, key)
  } catch { /* 静默降级 */ }
}

export async function idbGet(key: string): Promise<string | null> {
  try {
    const d = await openDB()
    return new Promise((resolve) => {
      const tx = d.transaction(STORE_NAME, 'readonly')
      const req = tx.objectStore(STORE_NAME).get(key)
      req.onsuccess = () => resolve(req.result ?? null)
      req.onerror = () => resolve(null)
    })
  } catch { return null }
}

// App 启动时：localStorage 为空但 IDB 有数据则自动恢复
export async function restoreFromIDB(keys: string[]): Promise<number> {
  let restored = 0
  for (const key of keys) {
    if (localStorage.getItem(key) === null) {
      const val = await idbGet(key)
      if (val !== null) { localStorage.setItem(key, val); restored++ }
    }
  }
  return restored
}
```

## 五、未来云同步的最小改造路径（P3）

核心约束：不修改现有 hook 对外接口。通过插入存储适配层实现。

```typescript
// src/lib/storageAdapter.ts

export interface StorageAdapter {
  getItem(key: string): string | null
  setItem(key: string, value: string): void
  removeItem(key: string): void
  onWrite?: (key: string, value: string) => Promise<void>
}

let adapter: StorageAdapter = {
  getItem: (k) => localStorage.getItem(k),
  setItem: (k, v) => {
    localStorage.setItem(k, v)
    idbSet(k, v).catch(() => {})
  },
  removeItem: (k) => localStorage.removeItem(k),
}

export const storage = {
  get: (k: string) => adapter.getItem(k),
  set: (k: string, v: string) => {
    adapter.setItem(k, v)
    adapter.onWrite?.(k, v)
  },
  remove: (k: string) => adapter.removeItem(k),
  useAdapter: (a: StorageAdapter) => { adapter = a },
}
```

接入云同步时，只需在 `App.tsx` 中调用一次 `storage.useAdapter(createCloudAdapter(userId))`，所有 hook 零改动。四个 hook 文件的改动量合计约18行替换调用，hook 返回值完全不变。

## 六、备份提醒时机设计（P2）

| 时机 | 触发条件 | 展示方式 |
|---|---|---|
| 里程碑触发 | 背完第5/15/30首诗 | 成就弹窗下方追加备份入口 |
| 超期未备份 | 距上次导出超7天且有新记录 | 首页顶部可关闭 Banner |
| 容量预警联动 | 使用率超过70% | 设置页入口显示角标 |
| 首次使用后3天 | 有连续打卡记录且从未备份 | 一次性引导提示 |

```typescript
// src/hooks/useBackupReminder.ts
export function useBackupReminder(totalMemorized: number) {
  const [show, setShow] = useState(false)
  const [reason, setReason] = useState('')

  useEffect(() => {
    const lastBackup = localStorage.getItem('poem_last_backup_date')
    const dismissed = sessionStorage.getItem('backup_reminder_dismissed')
    if (dismissed) return

    const today = new Date().toISOString().slice(0, 10)
    const daysSinceBackup = lastBackup
      ? (new Date(today).getTime() - new Date(lastBackup).getTime()) / 86400000
      : Infinity

    if (totalMemorized >= 3 && daysSinceBackup > 7) {
      setShow(true)
      setReason(lastBackup
        ? `距上次备份已 ${Math.floor(daysSinceBackup)} 天`
        : `你已背会 ${totalMemorized} 首诗，建议保存进度`)
    }
  }, [totalMemorized])

  const dismiss = () => {
    setShow(false)
    sessionStorage.setItem('backup_reminder_dismissed', '1')
  }

  return { show, reason, dismiss }
}
```
