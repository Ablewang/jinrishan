# T7 · 每周学习报告页

**类型：** 新功能  
**优先级：** P2  
**估算工时：** 2–3天  
**UI改动：** 新增路由 `/weekly-report`；首页红点提示

---

## 需求

### 功能需求

**报告内容（本周数据）：**

| 字段 | 数据来源 |
|---|---|
| 本周背了几首 | `poem_memorize_history` 按 date 过滤本周范围 |
| 打卡天数 / 7天 | history 中提取本周各天是否有记录 |
| 连续打卡天数 | `poem_streak.count`（T3完成后改为 `srs_streak_v2.count`） |
| 本周最难的诗 | `review_schedules` 中 ef 最低的本周已背诗 |
| 本周满星首数 | `recitation_sessions` 中本周 stars===3 的 poemId 去重计数 |
| 累计字数 | `poem_total_chars` |

**触发逻辑：**
1. 新增路由 `/weekly-report`，独立页面
2. App 启动时检查：上周有背诵记录（`poem_memorize_history` 中有上周日期）且 `poem_last_report_week` !== 上周周数
3. 满足条件时，首页"学习记录"入口显示红点
4. 用户访问报告页后，写入 `poem_last_report_week = 上周周数`，红点消失

**分享：**
- 报告页底部提供"分享本周战报"按钮
- 触发现有 ShareCardModal，type 扩展为 `'weekly'`，内容包含本周背诵首数 + 连续天数

## 验收标准

- [ ] 有上周记录时，首页"学习记录"入口显示红点
- [ ] 访问报告页后红点消失，当周不再重复出现
- [ ] 报告数据与 localStorage 实际数据一致
- [ ] 打卡日历正确标出本周有记录的天
- [ ] 点击分享触发 ShareCardModal，内容包含本周数据
- [ ] 无上周记录时，报告页显示空状态提示而非空白
