# 古诗学习 App — 进度可视化扩展方案

## 一、当前进度页现状分析

### 展示了什么

**四格统计 tiles**：已背诵数、已掌握数、累计字数、连续天数。数字清晰，一目了然。

**总体进度条**：已背 / 70 首的线性进度，目标感明确。

**间隔复习面板**：今日到期、复习中、已掌握三态；即将到期列表前 5 条；可直接跳转背诵。

**成就勋章格**：解锁/未解锁状态，含进度提示。

**已背诗目列表**：按星级（无提示/少量提示/多次提示）可过滤，点击可跳转。

### 缺失了什么

| 缺失项 | 相关字段 | 影响 |
|--------|---------|------|
| 时间维度完全缺失 | `recitation_sessions[].date` | 用户无法感知"我最近是否在坚持" |
| SM-2 EF 值未呈现 | `review_schedules[poemId].ef` | 难度感知全无，ef 越低越难，从未在 UI 显示 |
| 单诗进步曲线缺失 | `session.stars/passRate/qScore` | 完全支持折线图但未消费 |
| 逐行薄弱点不可见 | `session.lines[].hintCount/passed` | 精确定位"哪句最容易忘"的数据被埋没 |
| 亲子模式数据割裂 | `LineResult.mode` / `session.mode` | 亲子协作价值未可视化 |
| 最佳时段无感知 | `session.timestamp`（Unix ms） | 可计算每小时背诵质量分布，未使用 |

总结：当前页是一张静态快照，只回答"我背了多少"，无法回答"我怎么进步的""哪里最薄弱""什么时候状态最好"。数据层已非常充分，缺的只是可视化消费。

## 二、可新增的可视化模块

### M1 · 学习热力图（日历热力图）

**数据来源**：`recitation_sessions[].date`、`recitation_sessions[].stars`、`poem_streak`

**展示什么**：过去 12 周的日历格，每格颜色深浅表示当天背诵星数总和（0=空白，1=淡红，2=中红，3+=深红）。右侧显示当前连续天数和历史最长连续天数。

计算逻辑：按 `date` 分组，对每天所有 `session.stars` 求和，颜色用 4 档阈值（0/1/3/6 总星数）映射。

**UI 草图**：
```
┌─────────────────────────────────────┐
│  学习日历                             │
│                                       │
│  周一 ■ □ ■ □ □ ■ ■ □ ■ □ □ ■       │
│  周二 □ ■ ■ ■ □ □ □ ■ ■ ■ □ □       │
│  周三 ■ ■ □ ■ ■ □ ■ □ □ ■ ■ □       │
│  周四 □ □ ■ □ ■ ■ □ ■ □ □ ■ ■       │
│  周五 ■ □ □ ■ □ ■ ■ □ ■ ■ □ □       │
│  周六 ■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■ ■       │
│  周日 □ ■ □ □ ■ □ □ ■ □ □ ■ □       │
│                                       │
│  ■深红=3星 ■中红=2星 ■淡红=1星 □无    │
│         连续打卡 14 天  最长 21 天      │
└─────────────────────────────────────┘
```

**实现要点**：
- 纯 SVG 或 CSS grid 绘制，不需要图表库
- 每个格子 12×12px 圆角方块，gap 2px
- 数据来自 `recitation_sessions`（全量加载一次，O(n) 聚合）
- 连续天数直接读 `poem_streak.count`，无需重算

### M2 · 单诗背诵历程曲线

**数据来源**：`session.poemId`、`session.stars`、`session.passRate`、`session.qScore`、`session.date`、`review_schedules[poemId].ef`

**展示什么**：在诗词详情页展示该诗所有背诵记录折线图。X 轴为背诵次数，Y 轴为 `qScore`（0-5，SM-2 质量评分），叠加 `passRate` 面积填充。EF 值显示在右上角：≥2.5=轻松，1.8–2.5=还在练，<1.8=硬骨头。

**UI 草图**：
```
《静夜思》历程                  EF: 2.1 ▼ 偏难
5 ┤                      ●
4 ┤              ●   ●
3 ┤      ●   ●
2 ┤  ●
1 ┤
  └──────────────────────────
    1次  2次  3次  4次  5次  6次
  ▓▓▓ passRate 背出率（面积）
  ─── qScore 质量分（折线）
```

**实现要点**：
- 用 `useRecitation().getPoemSessions(poemId)` 获取记录
- SVG 折线 + 面积图，viewBox 自适应数据点数量
- 少于 2 次记录时展示引导文案"背诵第 2 次后可查看进步曲线"
- 封装为独立组件 `<PoemProgressChart poemId={id} />`

### M3 · 逐句薄弱点分析

**数据来源**：`session.lines[].lineIndex`、`session.lines[].passed`、`session.lines[].hintCount`、`session.poemId`

**展示什么**：针对单首诗，展示每句的历史通过率和平均提示次数。每行左侧有横向热度条，红色越深=越容易忘。

**UI 草图**：
```
《春晓》逐句难度
                         通过率  提示均值
床前明月光，    ████████ 90%    0.1
疑是地上霜。    ████████ 85%    0.2
举头望明月，    █████░░░ 60%    0.8  ← 薄弱
低头思故乡。    ███░░░░░ 40%    1.4  ← 最难
```

**实现要点**：
- 数据聚合纯 JS，O(n×lines) 时间，无需额外库
- 通过率热度条用 CSS linear-gradient，无需 SVG
- 嵌入诗词详情页"复习"tab 下方

### M4 · 难诗排行（基于 EF 值）

**数据来源**：`review_schedules[poemId].ef`、`review_schedules[poemId].totalSessions`、`review_schedules[poemId].bestStars`

**展示什么**：从 `review_schedules` 取所有诗的 EF 值，升序排列，取前 5 首"最难诗"。显示诗名、EF 值、已练次数。EF < 1.8 标红。过滤条件：`totalSessions >= 2`。

**UI 草图**：
```
最难啃的诗 Top 5               EF 越低越难
─────────────────────────────────────
红 《登高》           EF 1.4  已练 8次
红 《将进酒》         EF 1.7  已练 6次
橙 《出塞》           EF 2.0  已练 5次
绿 《悯农》           EF 2.4  已练 3次
绿 《静夜思》         EF 2.6  已练 4次
```

### M5 · 最佳学习时段分析

**数据来源**：`session.timestamp`（Unix ms）、`session.qScore`、`session.stars`

**展示什么**：按 `timestamp` 提取小时（0-23），聚合每时段平均 `qScore` 和背诵频次。柱状图展示 24 小时分布，高亮最佳时段（qScore 均值最高且频次 ≥ 3）。

**UI 草图**：
```
最佳学习时段
avg qScore
5 ┤
4 ┤              ████          ★最佳时段
3 ┤    ██  ██    ████  ██         19:00–20:00
2 ┤    ██  ██    ████  ████       avg 4.2分
1 ┤    ██  ██    ████  ████
  └──────────────────────────────
   7  9  11  14  16  19  21  23时
```

### M6 · 亲子模式效果对比

**数据来源**：`session.mode`、`session.stars`、`session.passRate`、`session.hintRate`、`session.qScore`

**展示什么**：将所有 session 按 `mode: 'parent' | 'child'` 分组，对比平均 passRate、平均 hintRate、3 星率。

**UI 草图**：
```
亲子协作效果对比
                孩子独立    亲子一起
平均通过率     ████ 72%    ██████ 88%   +16%
平均提示率     ████ 35%    ██ 18%       -17%
三星率         ████ 45%    ██████ 68%   +23%
```

## 三、各模块实现复杂度评估

| 模块 | 复杂度 | 估算工时 | 主要难点 |
|------|--------|---------|---------|
| M4 难诗排行 | 简单 | 1–2h | 纯数据处理，无图表，只需列表 UI |
| M3 逐句薄弱点 | 简单 | 2–3h | 数据聚合 + 热度条 CSS |
| M1 学习热力图 | 中等 | 3–5h | 日历格子布局、颜色映射、移动端适配 |
| M2 单诗历程曲线 | 中等 | 3–5h | SVG 折线+面积图坐标计算 |
| M5 最佳时段分析 | 中等 | 3–4h | 24 柱 SVG + 最佳区间高亮 |
| M6 亲子对比 | 复杂 | 5–8h | 双数据源统一、mode 字段历史兼容 |

## 四、推荐改版优先级 & UI 布局建议

**第一波**：M4 难诗排行 + M3 逐句薄弱点。数据可靠、实现简单、直接提升复习效率。

**第二波**：M1 学习热力图。最能提升打卡感和成就感，放在四格统计下方。

**第三波**：M2 单诗历程曲线 + M5 最佳时段分析。作为独立 tab 或折叠区块。

**第四波**：M6 亲子对比。在亲子功能有足够 DAU 后再做。
