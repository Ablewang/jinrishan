# T12 · PWA 推送通知 — 原型图

## 设置页「学习提醒」区块（改版）

```
┌─────────────────────────────────────────┐
│  学习提醒                                 │
├─────────────────────────────────────────┤
│                                          │
│  每日提醒          ●─────  开启          │
│                                          │
│  提醒时间                                │
│  ┌──────────────────────────────────┐   │
│  │  19:30                        ▼  │   │
│  └──────────────────────────────────┘   │
│                                          │
│  提醒内容                                │
│  当天有复习任务时自动提示数量              │
│                                          │
└─────────────────────────────────────────┘
```

## 开启提醒时系统授权提示

```
┌─────────────────────────────────────────┐
│  "古诗小课堂" 想要给您发送通知            │
│                                          │
│  通知可能包括提醒、声音和图标标记          │
│                                          │
│  [ 不允许 ]              [ 允许 ]        │
└─────────────────────────────────────────┘
```
（系统原生弹窗，样式由 OS 决定）
