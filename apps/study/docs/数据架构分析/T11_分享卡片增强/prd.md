# T11 · 分享卡片增强（里程碑 / 满星 / 周报卡）

**类型：** 新功能  
**优先级：** P2  
**估算工时：** 1–2天  
**UI改动：** ShareCardModal 新增3种卡片类型；成就弹窗新增触发时机

---

## 背景

当前分享卡片（ShareCardModal）只有一种类型：昵称 + 总字数 + streak 数字。`poem_memorize_history` 和 `poem_progress` 中有更丰富的内容可以呈现，让分享更有叙事感。

---

## 需求

### 新增3种卡片类型

**1. 里程碑卡（`type: 'milestone'`）**
- 触发时机：背诵首数突破 10 / 20 / 35 / 50 / 70 时，成就弹窗消失后自动弹出
- 内容：「刚刚背完第 N 首！」+ 对应等级称号 + 累计字数

**2. 满星成就卡（`type: 'perfect'`）**
- 触发时机：某首诗首次获得3星（`bestStars` 从 <3 变为 3）
- 内容：「无提示背完《XXX》！」+ 诗的第一句 + 连续天数

**3. 周报摘要卡（`type: 'weekly'`）**
- 触发时机：T7 每周报告页底部"分享本周战报"按钮
- 内容：本周背了 N 首 + 连续天数 + 本周最难克服的诗

### 技术改动

`ShareCardContext` 的 `params.type` 扩展：
```ts
type ShareCardType = 'poem' | 'checkin' | 'milestone' | 'weekly' | 'perfect'
```

每种类型对应不同的卡片布局和配色，在 `ShareCardModal.tsx` 中按 type 分支渲染。

## 界面设计要点

**里程碑卡：**
```
┌────────────────────┐
│   🎉 第 20 首！    │
│                    │
│   初入诗境         │  ← 等级称号
│   已积累 1,280 字  │
│                    │
│   古诗小课堂       │
└────────────────────┘
```

**满星成就卡：**
```
┌────────────────────┐
│   ⭐⭐⭐           │
│   无提示背完       │
│   《静夜思》       │
│                    │
│   床前明月光，     │  ← 第一句
│   连续打卡 14天    │
└────────────────────┘
```

## 验收标准

- [ ] 背诵首数达到里程碑值时，成就弹窗后自动弹出里程碑分享卡
- [ ] 首次3星时弹出满星卡，同一首诗只触发一次
- [ ] 周报页"分享"按钮弹出周报摘要卡，内容与报告页数据一致
- [ ] 三种卡片视觉风格与现有卡片一致（中国红主题）
- [ ] 每种类型的分享文字内容正确
