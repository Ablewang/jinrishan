# T6 · 进度页可视化增强（热力图 + 难诗排行）

**类型：** 新功能  
**优先级：** P1  
**估算工时：** 3–5天  
**UI改动：** ProgressPage 新增两个区块

---

## 背景

当前进度页是静态快照，只回答"我背了多少"。`recitation_sessions` 和 `review_schedules` 积累了大量时间维度和难度维度的数据，完全没有在 UI 中消费。

本期实现最高价值的两个模块：M1 学习热力图 + M4 难诗排行。

---

## 需求

### M1 · 学习热力图

**数据来源：** `recitation_sessions[].date`、`recitation_sessions[].stars`

**展示内容：**
- 过去 12 周的日历格（周一到周日 × 12列）
- 每格颜色深浅 = 当天所有 session 的 stars 总和
  - 0：空白（`#F5F0E8`）
  - 1–2：淡红（`rgba(198,40,40,0.25)`）
  - 3–5：中红（`rgba(198,40,40,0.55)`）
  - ≥6：深红（`#C62828`）
- 底部显示图例

**技术方案：** 纯 CSS grid，12列 × 7行，每格 12×12px 圆角方块，gap 3px，不引入图表库。

---

### M4 · 难诗排行

**数据来源：** `review_schedules[poemId].ef`、`review_schedules[poemId].totalSessions`

**展示内容：**
- 筛选条件：`totalSessions >= 2`（背过2次以上）
- 按 ef 升序排列，取前5首
- 每行展示：诗名 + EF值 + 已练次数 + 难度色标（ef<1.8=红，1.8–2.2=橙，>2.2=绿）
- 点击任意一行跳转到该诗详情页
