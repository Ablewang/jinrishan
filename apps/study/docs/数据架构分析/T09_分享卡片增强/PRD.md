# T09 · 分享卡片增强

## 背景

当前分享卡只有一种类型：昵称 + 总字数 + streak 天数。内容固定，缺乏即时感和叙事感。`poem_progress`、`poem_memorize_history` 中有丰富的具体内容（诗名、星级、里程碑），完全可以支撑更有吸引力的分享内容。

## 目标

新增3种分享卡类型，在特定时机自动弹出：
- 里程碑卡（背完第 N 首）
- 满星成就卡（首次3星通过）
- 周报摘要卡（T08 配套）

## 不在范围内

- 分享卡的视觉重设计（保持现有样式基础上扩展）
- 社交分享后台统计

## 功能需求

### 1. ShareCardContext 扩展

当前 `params.type` 扩展为：
```ts
type ShareCardType = 
  | 'poem'       // 现有：背完某首诗
  | 'checkin'    // 现有：打卡
  | 'milestone'  // 新增：里程碑
  | 'perfect'    // 新增：满星成就
  | 'weekly'     // 新增：周报摘要（T08 配套）
```

### 2. 里程碑卡（milestone）

触发时机：`poem_memorize_history` 长度达到 10 / 20 / 35 / 50 / 70 时

对应称号：
| 首数 | 称号 |
|---|---|
| 10 | 初入诗门 |
| 20 | 熟读成诵 |
| 35 | 诗意渐深 |
| 50 | 半部诗书 |
| 70 | 诗书满腹 |

卡片内容：「刚刚背完第 N 首！」+ 称号 + 最近背的诗名

触发逻辑：在 `markMemorized` 写入后，检查是否跨越里程碑，是则触发分享弹窗

### 3. 满星成就卡（perfect）

触发时机：`bestStars` 从 < 3 升级到 3 时（首次满星）

卡片内容：「无提示背完《XXX》！」+ 诗的第一行诗文

触发逻辑：`markMemorized` 中检测 `stars === 3 && oldBestStars < 3`

### 4. 周报摘要卡（weekly）

由 T08 的「分享本周报告」按钮触发，内容见 T08 PRD。

## 验收标准

- [ ] 背完第10首时自动弹出里程碑分享卡
- [ ] 里程碑时机只触发一次（已触发过则不重复弹出）
- [ ] 首次3星通过时自动弹出满星成就卡
- [ ] 用户可选择分享或关闭
- [ ] 3种新卡类型样式与现有卡片风格一致
