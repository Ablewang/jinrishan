# PRD — 间隔复习系统

版本：v1.0  
日期：2026-10-10  
状态：待评审

---

## 一、背景与目标

### 问题

现有 app 只有"背诗"功能，没有复习机制。用户背完一首诗后 app 对他没有后续价值，且无法保证长期记忆效果。

### 目标

1. **留存**：给用户每天回来的理由（今日有N首需要复习）
2. **效果**：基于遗忘曲线，确保背过的诗真正进入长期记忆
3. **可信**：家长能看到孩子"真的记住了"的证明，不只是背诵次数

### 不做

- 推送提醒（无后端）
- 动态算法（SM-2依赖精准自评，儿童不可靠）
- 年级/难度推荐（无推荐算法）

---

## 二、用户故事

**家长视角**
> 我希望孩子背过的诗不会很快忘掉，app 能告诉我孩子今天需要复习哪几首，复习完了才能学新的。

**孩子视角**
> 我今天要复习2首，背出来了就完成任务了，然后可以学一首新诗。

## 三、核心数据结构

### ReviewCard（每首背过的诗对应一张卡片）

```typescript
interface ReviewCard {
  id: number        // 诗 id
  level: number     // 当前档位 1-5，0=刚背完待首次复习
  due: string       // 下次复习日期 'YYYY-MM-DD'
  lastDate: string  // 最近一次背诵/复习日期
  passCount: number // 累计通过次数
}
```

### 间隔阶梯

| 档位 | 通过后下次间隔 |
|------|--------------|
| 0（刚背完）| 1天后 |
| 1 | 3天后 |
| 2 | 7天后 |
| 3 | 15天后 |
| 4 | 30天后 |
| 5（已掌握）| 不再出现在复习队列 |

- 任意档位**未通过** → 退回档位0，1天后重新复习
- 档位5 = 长期掌握，在诗集页显示"掌握"徽章

### localStorage key

```
poem_review_cards  →  ReviewCard[]
```

## 四、功能详情

### 4.1 首页改造

**今日任务区块**（替换现有的"今日背诵"区）

```
┌─────────────────────────────┐
│  今日任务                    │
│                             │
│  📖 复习  2首  [开始复习]    │
│  ✨ 新诗  1首  [开始学习]    │
│                             │
│  已完成 ✓                   │
└─────────────────────────────┘
```

规则：
- 复习：取 `due <= today` 的 ReviewCard，最多显示3首，超出顺延（不显示积压数字）
- 新诗：背诗计划队列第一首，**仅当今日复习全部完成后才高亮可点击**；复习未完成时新诗入口置灰但可点
- 全部完成（复习+新诗）→ 显示"今日完成"状态，streak +1

### 4.2 复习流程

复用现有 MemorizeMode，结束后新增**验证步骤**：

```
步骤1：遮住诗文，让孩子先尝试背（现有 MemorizeMode）
步骤2：背完后出现验证题
步骤3：根据答题结果更新 ReviewCard
```

**验证题设计（3选1）**：

```
┌─────────────────────────────┐
│  考考你 🎯                  │
│                             │
│  "床前明月光，"             │
│  下一句是？                 │
│                             │
│  ○ 疑是地上霜。  ← 正确    │
│  ○ 举头望明月。             │
│  ○ 春眠不觉晓。  ← 干扰项  │
│                             │
│  [确认]                     │
└─────────────────────────────┘
```

- 考题：随机取诗中某一句，要求选出正确的"下一句"
- 干扰项：从其他诗中随机抽取句子
- 答对 → 通过，ReviewCard 档位 +1，计算新 due
- 答错 → 未通过，ReviewCard 退回档位0，1天后重新复习
- 答题结果有明确的动画反馈（绿色✓ / 红色✗）

### 4.3 进度页新增"复习统计"

在现有进度页增加：
- 已掌握（档位5）：N首
- 复习中（档位1-4）：N首
- 待首次复习（档位0）：N首

### 4.4 ProfileSheet 改造

移除"每日提醒时间"（伪功能），替换为更有价值的**学习概览**：

```
┌─────────────────────────────┐
│  学习概览                   │
│                             │
│  已背诵   已掌握   坚持天数  │
│    12       5        7      │
│                             │
│  累计字数: 1,280字          │
└─────────────────────────────┘
```

## 五、边界情况

| 情况 | 处理方式 |
|------|---------|
| 今日复习 >3首到期 | 只取前3首，其余顺延到明天 |
| 背诗计划为空 | 首页不显示"新诗"入口，引导去添加 |
| 已掌握的诗再次背诵 | 不重置ReviewCard，只更新lastDate |
| 旧数据无ReviewCard | 首次加载时为已有memorized记录创建档位0的卡片 |
| 验证题诗只有一句 | 跳过验证，直接视为通过 |

## 六、验收标准

- [ ] 背完一首新诗后，次日首页出现该诗的复习任务
- [ ] 复习答对3次后，复习间隔依次为1→3→7天
- [ ] 答错后退回档位0，次日重新出现
- [ ] 每日复习上限3首，第4首及以后顺延
- [ ] 复习未完成时新诗入口可点但有视觉提示
- [ ] 档位5的诗在诗集页显示"已掌握"徽章
- [ ] ProfileSheet不再有"每日提醒"选项
