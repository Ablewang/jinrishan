# 「背一背」功能重设计方案

> 综合认知心理学、脑科学、教育学、游戏化设计、产品管理五学科专家意见  
> 今日山古诗学习应用 · 2026年9月

---

## 一、执行摘要

「背一背」当前交互机制在认知科学层面方向正确，高于市面主流产品（具备配图背景情境锚点、分轮脱手机制、揭字爆开微反馈），但三个核心问题削减了这个优势：

1. **900ms/600ms自动前进**剥夺了孩子的主动提取机会和自主感——孩子在被推着走，而非主动背诵。
2. **任意顺序点击**破坏了古诗的语义流完整性——「床前明月光」从第五个字开始揭会让整体记忆线断裂。
3. **单次体验缺乏留存钩子**——没有理由让孩子明天主动打开。

本方案聚焦三件事：把被动揭示升级为有强制思考窗口的主动提取；把「看答案」三级脚手架化并还权于孩子；把单次完成转化为有星级、streak和分享的持续学习习惯。**P0改动全部在现有MemorizeMode.tsx文件内完成，约半天工时，无需后端。**

## 二、核心学习原则（六条设计基准）

以下六条原则提炼自跨学科专家讨论，是后续所有设计决策的判断基准。

**原则①：主动提取优于被动揭示**  
点击揭字前，大脑必须先尝试检索。哪怕提取失败，失败尝试本身也会激活海马体记忆编码机制，使随后的正确答案编码更深。被动观看不激活这一机制。一次主动提取的记忆效果是三次重复阅读的1.5倍（Roediger & Karpicke 2006）。

**原则②：脚手架精准撤除，不硬跳**  
「有拼音→无拼音」是正确的渐进脱手方向（维果茨基ZPD），但「看答案」直接暴露全字是脚手架坍塌而非撤除。支撑应分阶梯：声母→拼音→汉字。同时改名为「提示一下」，文案本身对自我效能感有直接影响（Bandura 1977）。

**原则③：自主感是内在动机的前提**  
900ms自动前进剥夺了孩子的时间控制权。SDT理论明确：自主感是内在动机的基本需求。一个感到被推着走的孩子，在神经层面处于应激状态，学习效率显著下降（Deci & Ryan 2000）。

**原则④：意象先于文字**  
7岁孩子对「床前明月光」的理解是通过月光、霜、乡愁的具体意象完成的，而非命题语义。先建立视觉-情感情境再背诵，记忆留存率高出纯机械背诵约40%（Craik & Lockhart 1972；Egan 1989）。

**原则⑤：失败必须安全**  
7岁是自我效能感形成关键期，早期挫败体验的破坏性大于任何认知优化收益。错误无惩罚音效；归因指向任务难度而非自身能力（「这首诗稍难，多背几次就会了」）；竞争对象永远是昨天的自己（Bandura 1977；Eccles et al. 1993）。

**原则⑥：间隔复习把单次体验变成长期记忆**  
单次背诵24小时后遗忘约56%，一周后约77%。粗粒度间隔（当天→次日→3天→7天）已能将长期留存率从30%提升到超过80%（Ebbinghaus 1885；Cepeda et al. 2006）。

## 三、重新设计的学习流程

从「单次揭示体验」升级为「有前置铺垫、有主动提取、有结果分享」的完整学习旅程。整体时长4–8分钟，控制在7岁儿童注意力窗口内。

### 阶段0：今日任务入口
首页展示连续学习天数streak（火焰图标+数字）。已完成诗卡加「上次★★☆」星级标注，让孩子看到提升空间。复习诗（3天/7天后到期）标注「该复习啦」角标。

### 阶段1：入诗页（新增，P1）
全屏展示诗歌配图，叠加诗题、作者、朝代。「听一听」播放整首诗朗读（预录音频，约20秒）。1–2句儿童语言的意象说明建立情感锚点（例：「李白在外地，看到月光，想起了家乡…」）。「开始背」进入第一关，可跳过。

### 阶段2：第一关——拼音助阵（现有第一轮升级）
拼音可见。增加**「思考圈」机制**——每个圆圈出现时有1.5秒收缩弧线动画，动画完成前不可点击，强迫孩子先在脑中尝试提取。揭示顺序**严格从左到右**，下一个待揭字有轻微光晕引导。所有字揭示后显示「我背出来啦 ✓」按钮，**不自动跳转**——孩子决定何时继续。需要帮助点击「提示一下」（两阶：拼音→汉字）。

### 阶段3：轮间过渡屏（新增，P1）
第一轮最后一句确认后插入5秒过渡屏。文案：「太棒了！第一关完成。第二关没有拼音，准备好了吗？」这5秒消除猝不及防的挫败感。

### 阶段4：第二关——独立闯关（现有第二轮升级）
无拼音，思考圈延长到2秒。自己点出的字保持红色爆开动效；用提示后揭示的字以**琥珀色（#C47A0A）** 显示（信息性区分，非惩罚）。确认按钮双态：自己全部背出→「我背出来啦 ✓」；用了提示→「好，记住了」（语气中性）。

### 阶段5：庆祝页与学习报告
根据两轮合计提示次数动态调整：
- 0次 → ★★★ 超级庆祝（粒子×3）+「完美通关！一个提示都没用！」
- 1–2次 → ★★☆ 普通庆祝+「背得很好！下次试试不用提示」
- 3次以上 → ★☆☆ 温暖鼓励（无礼花）+「这首诗稍难，多背几次就会了！」

庆祝页包含学习报告卡和「发给爸妈看」按钮（navigator.share() 纯文字）。

## 四、交互细节

### 1. 思考圈强制提取窗口（P0）
每个圆圈出现时，边框上有一条收缩弧线（conic-gradient），1.5s/2s内收缩归零。弧线收缩期间 `pointer-events: none`。弧线消失时圆圈轻微脉冲（scale 1→1.08→1，100ms），提示现在可点击。「提示一下」始终可点击，不受约束。

### 2. 顺序揭示：语义流保护（P0）
修改 `revealChar(i)`：只接受 `idx === revealed.size` 时触发。待揭示的下一个圆圈显示轻微光晕（`mm-line__circle--next`）。约10行代码改动。

### 3. 手动确认按钮（P0）
删除 `useEffect` 中的 `setTimeout(nextLine, delay)`，`allRevealed` 时改为显示确认按钮。无提示时「我背出来啦 ✓」（红色），用了提示时「好，记住了」（琥珀色）。

### 4.「提示一下」双阶脚手架（P0）
「看答案」→「提示一下」。第一阶：显示当前句拼音。第二阶（「还是不会」）：显示完整汉字。

### 5. 提示后琥珀色字符（P0）
新增 CSS class `mm-line__hanzi--hinted`，颜色 `#C47A0A`。

## 六、进阶与留存系统

**连续学习Streak（P1，localStorage）**：首页展示连续天数，中断保护（1次补救机会）。

**三星历史记录（P1，localStorage）**：首页诗卡展示历史最佳星级，将「完成」升级为「精通」。

**三桶间隔复习系统（P2，需账号体系）**：新朋友（当天→次日）、老朋友（3天/7天）、永久点亮。长期留存率从30%提升到>80%。注意：微信内置浏览器清缓存会清空localStorage，此功能必须依赖后端账号体系。

**诗人地图（P2，aspirational）**：70首诗可视化为从村庄到长安的地图，背过的诗点亮地标，每10首到达新地点。

## 七、视觉与动效设计方向

**保留现有设计**：配图背景（opacity 0.2）、爆开动效（popChar）、礼花粒子（burstFly）、中国红 `#C62828`、ZCOOL KuaiLe字体——全部保留。

**新增内容**：
- 思考圈收缩弧：conic-gradient，#C62828，3px宽，1.5s/2s动画
- 下一个待揭字光晕：`box-shadow: 0 0 0 4px rgba(198,40,40,0.18)`
- 提示后琥珀色：`#C47A0A`（信息性区分，非惩罚）
- 三星庆祝差异化：★★★粒子×3；★★☆现有不变；★☆☆无礼花，配图淡入+温暖文字
- 入诗页（P1）：配图全屏+诗题大字+意象卡片（rgba(255,255,255,0.85)）

**音效**：揭示40ms轻柔pop；句通过200ms单音ding；三星1秒上升音型；「提示一下」无音效。
