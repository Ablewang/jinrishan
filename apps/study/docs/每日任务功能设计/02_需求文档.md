## 一、背景与目标

### 问题陈述

古诗小课堂当前的核心问题是**没有回访动力**：用户第一次打开背了一两首诗，之后再也不回来。产品像字典——有问题来查，没问题不打开。根本原因是缺乏每日任务结构，孩子没有"今天要做什么"的锚点，家长也没有工具来建立孩子的背诗习惯。

### 功能目标

1. 建立每日任务结构，让孩子每天有明确的一件事要做
2. 通过累计进度和里程碑奖励，让背诗成为有成就感的事
3. 降低家长的管理成本，家长只需设置一次年级即可启动

### 成功指标

- 次日留存率提升（目标：从当前基线提升 30%+）
- 7日留存率提升
- 日均启动次数增加

---

## 二、用户角色

| 角色 | 描述 | 核心诉求 |
|------|------|---------|
| 孩子（6-8岁） | 主要使用者，认字有限，需要极简操作 | 今天做什么？做完了有什么？ |
| 家长 | 决策者，设置任务，监督执行 | 设置简单，孩子能独立完成，能看到孩子在学 |

---

## 三、功能范围（P1 版本）

### 包含

- 年级设置（家长一次性配置）
- 今日任务推荐（系统自动，基于年级和进度）
- 首页今日任务横幅
- 累计背诵计数（主指标）
- 本周完成情况可视化（辅助指标）
- 间隔复习逻辑
- 任务完成庆祝动画（复用现有撒花效果）
- 里程碑奖励（诗人故事卡，5首、10首）

### 不包含（后续版本）

- PWA 推送通知（P1 降级为横幅触达，推送为增强功能）
- 智能推荐算法（第一版按年级顺序推进）
- 账号体系（跨设备同步需后端，Backlog）

## 四、详细需求

### 4.1 年级设置

**触发时机**：首次打开 app 时，或点击设置入口时

**流程**：
1. 进入年级设置页
2. 选择年级：一年级 / 二年级 / 三年级及以上
3. 确认 → 保存至 localStorage

**数据**：
```
userConfig.grade: 'grade1' | 'grade2' | 'grade3plus'
```

**诗词年级标注**（内容配置工作）：
- 70首诗每首需标注推荐年级
- 一年级：字数少、词汇简单，约15-20首
- 二年级：词汇适中，约20-25首
- 三年级及以上：剩余所有诗

**注意**：家长可随时修改年级，修改后今日任务推荐立即更新

---

### 4.2 今日任务推荐

**推荐规则**：

1. 取当前年级及以下所有诗（如选二年级，包含一年级诗目）
2. 找出尚未背诵过的诗中，顺序排列取第一首 → 作为**新诗任务**
3. 找出已背诵且距离上次背诵超过7天的诗 → 取距今最远的一首 → 作为**复习任务**
4. 若无可复习的诗，则只有新诗任务
5. 若年级内所有诗均已背诵完，从头重新推荐，并在首页提示"开始第二轮"

**缓存策略**：
- 推荐结果按当天日期缓存（`YYYY-MM-DD` 为 key）
- 当天内不重新计算，确保任务稳定
- 次日0点后刷新（下次进入 app 时重新计算）

**展示策略**：
- 对孩子不区分"新诗"和"复习"，统称"今天的诗"
- 两首诗分别展示，孩子依次完成

---

### 4.3 首页今日任务横幅

**位置**：首页顶部，navbar 下方第一个区块，优先级高于进度条

**三种状态**：

**状态 A：已设置年级，今日未完成**
- 背景色：暖橙色（`#FF8C00` / `rgba(255, 140, 0, 0.12)` 浅色底）
- 主文案：`今天的诗来了！`
- 副文案：诗名1 · 诗名2（若只有一首则只显示一首）
- 按钮：`开始背诵`（大按钮，醒目）
- 辅助：本周完成情况（7个小圆点）

**状态 B：今日已完成**
- 背景色：暖绿/金色（`#52C41A` / 浅绿底）
- 主文案：`今天完成了！`
- 副文案：已背 X 首诗 · 本周第 N 天
- 按钮：`再背一首`（次要样式按钮）

**状态 C：未设置年级**
- 背景色：中性浅色
- 主文案：`设置年级，开始每日任务`
- 按钮：`去设置`

**交互**：
- 点击"开始背诵" → 进入第一首诗的背一背流程
- 完成第一首后，若有复习任务，自动引导至第二首
- 两首均完成 → 触发庆祝动画 → 更新横幅为状态 B

---

### 4.4 累计计数与本周进度

**累计背诵首数**（主指标）：
- 数据来源：复用现有 `totalMemorized`
- 展示位置：首页横幅内、进度页统计格
- 特征：永远只增不减，断天数不影响

**本周完成情况**（辅助指标）：
- 数据结构：记录每周（周一到周日）每天是否完成今日任务
  ```
  weekProgress: { 'YYYY-WNN': [false, true, true, false, false, false, false] }
  ```
  其中数组下标0=周一，6=周日
- 展示形式：7个小圆点，完成的实心亮色（红色主题），未完成的空心灰色
- 展示位置：首页横幅内（一行小图标）
- 语气：描述性，不是考核性。今天没完成不显示警告色，明天仍然欢迎

**断档处理**：
- 昨天未完成：横幅文案不变，不显示"昨天你没来"等负面信息
- 连续多天未完成：仍然是正常的"今天的诗来了"，不是惩罚性语气

---

### 4.5 里程碑奖励

**触发时机**：累计背诵首数达到里程碑值时，完成庆祝动画后弹出里程碑卡片

**P1 版本里程碑**：

| 首数 | 奖励内容 | 内容规格 |
|------|---------|---------|
| 5首 | 解锁「李白的故事」诗人卡 | 300-400字简介 + 1张水墨风插图 |
| 10首 | 解锁「杜甫的故事」诗人卡 | 同上 |
| 20首 | 解锁「苏轼的故事」诗人卡 | 同上 |
| 50首 | 特别成就卡（可分享） | 生成分享图 |

**里程碑进度可见**：
- 在进度页或成就页展示"再背X首，解锁下一个诗人故事"
- 让孩子提前知道下一个奖励在哪里

**诗人故事卡展示**：
- 全屏弹出卡片，图文结合
- 可保存到"我的故事"（进度页一个新区块）
- 随时可重读

### 4.6 数据模型（localStorage）

在现有数据基础上新增以下字段：

```typescript
// 用户配置
interface UserConfig {
  grade: 'grade1' | 'grade2' | 'grade3plus' | null
  setupDone: boolean
}

// 今日任务缓存
interface DailyTaskCache {
  date: string           // 'YYYY-MM-DD'
  newPoemId: number | null
  reviewPoemId: number | null
  newPoemDone: boolean
  reviewPoemDone: boolean
}

// 本周完成记录
interface WeekProgress {
  weekKey: string        // 'YYYY-WNN'（ISO 周）
  days: boolean[]        // 7项，索引0=周一
}

// 已解锁里程碑
interface UnlockedMilestones {
  ids: number[]          // 已解锁的里程碑 id 列表
  seen: number[]         // 已看过的里程碑（避免重复弹出）
}
```

## 五、交互流程

### 主流程：孩子完成今日任务

```
打开 app
  → 首页显示「今天的诗来了！」横幅
  → 点击「开始背诵」
  → 进入诗详情页（三关背诵流程）
  → 完成三关
  → 触发撒花庆祝动画
  → 检查是否达到里程碑 → 是：弹出里程碑卡片
  → 检查是否有复习任务 → 是：引导「还有一首要背」
  → 完成复习任务（同上流程）
  → 横幅更新为「今天完成了！」
  → 本周进度点亮今天
```

### 首次使用流程

```
首次打开 app
  → 检测是否已设置年级
  → 未设置：显示年级设置引导
  → 选择年级 → 确认
  → 返回首页，横幅显示第一个任务
```

## 六、内容制作需求

以下为非技术工作，需协调内容团队：

1. **70首诗年级标注**：每首诗标注 grade1 / grade2 / grade3plus
2. **诗人故事卡内容**：
   - 李白：300-400字，适合6-8岁阅读，搭配水墨风插图
   - 杜甫：同上
   - 苏轼：同上
3. **断档安慰文案**：温暖、简短，不超过20字，避免负面情绪
4. **里程碑庆祝文案**：配合每个里程碑节点

---

## 七、非功能需求

- 离线可用：所有功能纯前端实现，无网络依赖
- 性能：首页加载（含今日任务推荐计算）< 300ms
- 兼容性：iOS Safari 14+，Android Chrome 88+
- 无障碍：按钮有足够的点击区域（最小 44×44pt），色彩对比度满足 WCAG AA

---

## 八、验收标准

- [ ] 家长可在3步内完成年级设置
- [ ] 首页今日任务横幅在设置年级后正确显示
- [ ] 今日任务每天自动更新，当天内稳定
- [ ] 完成今日任务后横幅状态正确切换
- [ ] 累计首数在完成背诵后正确增加
- [ ] 本周7格进度在完成今日任务后正确点亮
- [ ] 达到5首里程碑时，李白故事卡正确弹出
- [ ] 故事卡可重新查看
- [ ] 换设备数据丢失时，产品内有温和说明
