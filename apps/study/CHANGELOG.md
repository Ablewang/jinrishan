# Changelog

## v2.0.0 (2026-10-14)

### 新功能

- **Onboarding 引导页**：全新欢迎流程，Logo 跑入动画、诗句主视觉、入门关卡选诗
- **激励体系**：成就系统、连续学习天数追踪、成果分享卡片
- **间隔复习优化**：复习队列管理优化，明日到期提前预览
- **UI 全面升级**：首页改版（Hero 区块、任务卡片）、底部抽屉我的页面

### 修复

- **iOS 27 PWA 顶部 Liquid Glass 蒙层**：`body` 内联红色背景，让系统在 JS 执行前采样到正确颜色
- **引导页横向滚动**：改回 `position: fixed; inset: 0` 脱离文档流
- **引导页宽度异常**：修复在宽屏设备上内容靠左问题
- **PWA 启动白屏**：返回按钮用 `location.key` 判断历史记录
- **禁止页面缩放**：viewport 加 `maximum-scale=1.0, user-scalable=no`
- **详情页返回按钮**：无历史时跳回首页而非空白

## v1.0.0 (2026-09-22)

### 新功能

- **70首古诗学习**：小学必背古诗完整收录，带拼音、注释、译文
- **三关渐进式背诵**：
  - 第一关：随机遮挡约 50% 汉字，有拼音提示，逐字点击揭开
  - 第二关：整句来，首字拼音提示，点击整行揭开
  - 第三关：去掉所有拼音，全凭记忆
- **间隔复习系统**：基于遗忘曲线的科学复习调度
- **每日任务系统**：每日背诗计划，连续学习天数统计
- **成就页**：学习里程碑记录
- **底部导航**：常驻 Tab Bar，SVG 图标
- **我的页面**：Sheet 浮层展示学习数据
- **詩集列表**：全部/已背/未背筛选
- **进度页**：学习进度可视化
- **PWA 支持**：可安装到桌面，离线可用
- **骨架屏 + 波浪字加载动画**：详情页加载体验优化
- **书环装饰**：诗集详情页笔记本风格装饰
- **背一背悬浮按钮**：支持拖拽吸边
- **撒花庆祝动画**：背诵完成全屏礼花
