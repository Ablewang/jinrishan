# 购买清单功能规划

## 功能概述

用户可以将想拼的物品加入「想拼列表」，同时录入自己已有的拼豆库存，系统自动计算每个物品缺少的颜色和数量，汇总成购买清单。

---

## 核心概念

- **想拼列表**：用户收藏的待拼物品，按分类分组
- **已有库存**：用户已购买的各色拼豆数量（按色号记录）
- **购买清单**：想拼列表所需总量 - 已有库存 = 需购买数量

---

## 数据结构（localStorage）

```ts
// 想拼列表（与色板无关，物品名称两套相同）
wishlist: { cat: string; name: string }[]

// 已有库存（按色板分开存储，因为两套色板同色号 hex 不同）
inventory_221:  Record<string, number>  // { 'A1': 200, 'B3': 50, ... }
inventory_full: Record<string, number>
```

> 想拼列表不区分色板（物品是同一套），库存区分色板（颜色豆不同）。

---

## 页面与交互

### 1. 详情页（DetailPage）

- Header 右侧加「+ 想拼」/「已在列表」切换按钮
- 点击加入/移除想拼列表

### 2. 分类页（CategoryPage）

- 每个物品行右侧显示「+ 想拼」图标
- 分类页 Header 加「整组添加」按钮，将整个分类加入想拼列表

### 3. 新页面：想拼列表页（WishlistPage）

- 入口：首页 Header 加「想拼」按钮
- 按分类分组展示已添加的物品
- 每组可整组移除，每个物品可单独移除
- 底部固定「查看购买清单」按钮

### 4. 新页面：购买清单页（PurchasePage）

- 展示所有想拼物品所需颜色汇总
- 每一行：色块 + 色号 + 色名 + 需购买数量（= 总需量 - 库存）
- 库存为 0 的颜色标红，已满足的标绿
- 每行可点击直接编辑该色号的库存数量
- 顶部显示：X 种颜色待购买 / Y 种已满足

### 5. 库存录入（内嵌在购买清单页）

- 点击某行颜色 → 弹出数字输入框录入持有数量
- 数据实时存入 localStorage

---

## 导航流

```
首页
├── [想拼] → 想拼列表页
│              └── [查看购买清单] → 购买清单页（含库存录入）
├── 分类页
│   └── 物品行 [+想拼]
└── 详情页
    └── Header [+想拼 / 已在列表]
```

---

## 实现步骤

1. `useWishlist` hook — localStorage 读写想拼列表
2. `useInventory` hook — localStorage 读写库存
3. DetailPage — 加想拼按钮
4. CategoryPage — 加单个/整组想拼按钮
5. WishlistPage — 想拼列表展示页
6. PurchasePage — 购买清单 + 库存录入
7. 首页 Header — 加「想拼」入口按钮
