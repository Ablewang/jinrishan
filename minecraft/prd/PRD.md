## 一、背景与目标

### 1.1 项目背景

本项目已通过 Python 脚本（`batch_pindou.py`）将 Minecraft 物品像素图批量转换为拼豆指导图，生成了以下数据资产：

| 分类 | 物品数量 | 总拼豆数 | 颜色数 |
|------|---------|---------|--------|
| Building Blocks | 176 | 27,309 | 125 |
| Decorations | 517 | 70,754 | 178 |
| Materials | 271 | 33,785 | 146 |
| Miscellaneous | 250 | 31,446 | 199 |
| Spawn Eggs | 83 | 12,756 | 149 |
| Food & Drinks | 70 | 8,239 | 125 |
| Redstone | 54 | 4,142 | 62 |
| Combat | 44 | 4,042 | 37 |
| Tools | 24 | 1,433 | 26 |

每个物品对应：
- `.json` 文件：含 16×16 网格颜色数据 + 材料清单（颜色代码、中文名、RGB、数量）
- `.png` 文件：已生成的拼豆指导图（高清 3×，实际显示 390px 宽）
- `gallery/` 下同名 `.png`：缩略图/预览图
- `output/_summary.png`、`summary.json`：分类汇总统计

### 1.2 目标

开发一套纯前端 HTML 页面，将上述数据可视化，让用户可以：

1. 按分类浏览所有 Minecraft 拼豆图案
2. 查看单个物品的拼豆网格预览（20×20 板子，含序号）
3. 查看单个物品的材料清单（每种颜色的代码、名称、数量）
4. 汇总查看跨分类的材料总需求（"我要做哪些，共需要多少颗各色拼豆"）

### 1.3 非目标

- 不需要后端服务，纯静态 HTML + JS
- 不需要用户登录/账号体系
- 不需要在线编辑拼豆图案

## 二、用户场景

### 场景 A — 选款浏览
> 用户想做一套 Redstone 系列拼豆，先浏览所有 Redstone 物品，挑选感兴趣的款式。

### 场景 B — 制作参考
> 用户选中"红石块"，打开详情页，对照 20×20 网格图逐格摆放拼豆，旁边显示材料清单作参考。

### 场景 C — 备料汇总
> 用户计划做完整 Redstone 分类，点"清单汇总"，在 Redstone Tab 下看到所有颜色的总用量，去淘宝采购。

## 三、页面架构

```
首页（分类列表）
  ├── 分类页（某分类物品列表）
  │     └── 详情页（单个物品拼豆网格 + 材料清单）
  └── 清单汇总页（跨分类材料统计）
```

共 4 个视图，单页应用（SPA），URL hash 路由区分。

## 四、功能模块详细设计

### 4.1 首页（Home）

**路由**: `#/`

#### 布局
- 顶部 Header：左侧"分类"标题，右侧"清单汇总"文字按钮（点击跳转清单汇总页）
- 主体：二列网格，每个分类一张卡片

#### 分类卡片
| 元素 | 说明 |
|------|------|
| 缩略图 | 使用 `output/{分类}/_summary.png` |
| 名称 | 分类英文名（如 "Redstone"） |
| 总数标签 | "54 款" |
| 点击行为 | 跳转对应分类页 `#/category/{分类名}` |

#### 分类卡片顺序（建议）
1. Building Blocks
2. Decorations
3. Materials
4. Miscellaneous
5. Spawn Eggs
6. Food & Drinks
7. Redstone
8. Combat
9. Tools

#### 视觉规格
- 背景色：`#1a1a1a`（深黑）
- 卡片边框：`2px solid rgba(255,60,60,0.7)`（红色描边）
- 卡片圆角：`12px`
- 文字颜色：`#ff4444`（红色系，Minecraft 风格）
- 悬停效果：边框亮度提升，轻微放大（`scale(1.02)`）

---

### 4.2 分类页（Category）

**路由**: `#/category/{categoryName}`

#### 布局
- 顶部 Header：左侧 `←` 返回按钮 + 分类名称，右侧"清单汇总"文字按钮
- 筛选框：全宽输入框，placeholder "搜索物品名称..."，**支持中文拼音/汉字**
- 物品列表：纵向滚动列表

#### 筛选逻辑
- 同时匹配：
  - 物品英文 key（如 `redstone_block`）
  - 物品中文 display_name（如 `红石块`）
- 不区分大小写
- 实时过滤（`oninput` 事件）
- 中文输入法防抖：监听 `compositionstart` / `compositionend`，合成期间不触发过滤

#### 物品列表项
| 元素 | 说明 |
|------|------|
| 左侧小图 | `gallery/{分类}/{物品名}.png`，48×48px |
| 物品名称 | 中文 display_name，加粗 |
| 副标题 | 英文 key（灰色小字） |
| 右侧数字 | 拼豆总数，如 "176 颗" |
| 点击行为 | 跳转详情页 `#/item/{分类}/{物品名}` |

---

### 4.3 详情页（Item Detail）

**路由**: `#/item/{categoryName}/{itemName}`

#### 布局
- 顶部 Header：左侧 `←` 返回按钮 + `{中文名} 拼豆预览 (20×20)`，右侧无
- 区域一：拼豆网格预览
- 区域二：材料清单

#### 拼豆网格预览区

**数据来源**: `output/{分类}/{物品名}.json` 中的 `grid` 字段（16×16 数组）+ `materials`（颜色映射）

**渲染规则**:
- 网格尺寸：16 列 × 16 行（grid 数据）
- 显示在 20×20 的底板上：grid 内容居中放置，上下左右各留 2 格空白（底板格）
- 每格大小：自适应，保证整体宽度 = 屏幕宽度 - 2×序号列宽 - 2×padding
- 格子内容：
  - `null` → 空白（浅灰色，无拼豆）
  - 颜色代码（如 `"F10"`）→ 填充对应 RGB 颜色
- 序号标注：
  - 顶部一行：列序号 1–20（居中，小字）
  - 左侧一列：行序号 1–20（居中，小字）
- 底板格（超出 16×16 的区域）：显示为淡灰色背景，区别于有拼豆的格子
- 网格线：细线分隔每格

**交互**:
- 点击某格：若有颜色，高亮同色所有格子（用边框或亮度变化标注），同时在材料清单中对应行高亮
- 再次点击：取消高亮

#### 材料清单区

**数据来源**: 同一 JSON 文件的 `materials` 数组

**标题**: "材料清单"，下方分割线

**列表项**（按数量降序排列）:
| 元素 | 说明 |
|------|------|
| 颜色样本 | 20×20px 方块，填充对应 RGB |
| 颜色代码 | 如 `F10`，等宽字体 |
| 颜色名称 | 如 `红棕色` |
| 数量 | 如 `49 颗`，加粗，右对齐 |
| 占比 | 如 `(27.8%)`，灰色小字 |

**滚动**: 当列表超出区域时，该区域独立滚动（`overflow-y: auto`），与网格区域互不干扰。

---

### 4.4 清单汇总页（Summary）

**路由**: `#/summary`

#### 布局
- 顶部 Header：左侧"分类"文字按钮（返回首页），右侧"清单汇总"标题（高亮/选中状态）
- Tab 栏：横向可滚动 Tab，含 "总计" + 各分类名
- 内容区：当前 Tab 对应的材料汇总列表

#### Tab 栏
- 支持横向滚动（移动端 `overflow-x: auto`，隐藏滚动条）
- 支持鼠标拖拽滚动（PC 端）
- 支持左右方向键切换 Tab
- 选中 Tab 下方显示红色指示线
- Tab 项：`总计` | `Building Blocks` | `Combat` | `Decorations` | `Food & Drinks` | `Materials` | `Miscellaneous` | `Redstone` | `Spawn Eggs` | `Tools`

#### 内容区（每个 Tab）

**数据来源**:
- 分类 Tab：`output/summary.json` 中 `categories[分类名].materials`
- 总计 Tab：将所有分类的 materials 按颜色代码合并汇总

**列表项**（与详情页材料清单相同格式，按数量降序）:
| 元素 | 说明 |
|------|------|
| 颜色样本 | RGB 色块 |
| 颜色代码 | 等宽字体 |
| 颜色名称 | 中文名 |
| 数量 | 颗数，加粗右对齐 |

**列表滚动**: 内容区独立滚动。

## 五、数据结构参考

### 5.1 物品 JSON（`output/{分类}/{物品名}.json`）

```jsonc
{
  "name": "redstone_block",          // 英文 key
  "display_name": "红石块",           // 中文名
  "grid_size": 16,                   // 网格尺寸
  "board_size": 20,                  // 底板尺寸
  "total_beads": 176,                // 拼豆总数
  "color_count": 6,                  // 颜色种数
  "grid": [                          // 16行 × 16列，null 或颜色代码
    [null, null, ..., "A15", ...],
    ...
  ],
  "materials": [
    {
      "code": "F10",                 // 颜色代码
      "name": "红棕色",               // 中文名
      "rgb": [115, 44, 2],           // RGB 值
      "count": 49,                   // 数量
      "pct": 27.8                    // 占比%
    },
    ...
  ]
}
```

### 5.2 汇总 JSON（`output/summary.json`）

```jsonc
{
  "categories": {
    "Redstone": {
      "total_beads": 4142,
      "color_count": 62,
      "materials": [ { "code": ..., "name": ..., "rgb": ..., "count": ..., "pct": ... }, ... ]
    },
    ...
  }
}
```

### 5.3 图片资源路径

```
output/{分类}/_summary.png           # 分类封面图（首页卡片用）
output/{分类}/{物品名}.png            # 拼豆指导图（高清）
gallery/{分类}/{物品名}.png           # 物品缩略图（分类页列表用）
```

## 六、技术规格

### 6.1 技术栈

- 纯 HTML + CSS + JavaScript（ES6+）
- 无框架依赖，无构建工具
- 单文件或多文件均可，推荐多文件结构：

```
minecraft/
  index.html          # 主入口，SPA 容器
  style.css           # 全局样式
  app.js              # 路由 + 视图渲染逻辑
  data-loader.js      # JSON 数据加载工具
```

### 6.2 路由

使用 `location.hash` 实现前端路由：

| 路由 | 视图 |
|------|------|
| `#/` 或空 | 首页 |
| `#/category/Redstone` | Redstone 分类页 |
| `#/item/Redstone/redstone_block` | 红石块详情页 |
| `#/summary` | 清单汇总页 |

### 6.3 数据加载

- 使用 `fetch()` 动态加载 JSON，避免一次性加载全部数据
- 分类页：按需加载该分类下所有物品的基础信息（可从 JSON 文件名 + 各文件读取）
- 详情页：按需加载单个物品 JSON
- 清单汇总页：加载 `summary.json`（一次性）

### 6.4 适配

- 目标设备：手机（主）+ PC（次）
- 设计稿宽度：390px（手机）
- 网格预览在 PC 上可适当放大

### 6.5 视觉主题

参考拼豆实物和草图风格：

```css
/* 主色调 */
--bg-primary: #1a1a1a;
--bg-card: #111111;
--accent: #ff4444;
--accent-dim: rgba(255, 68, 68, 0.6);
--text-primary: #ff4444;
--text-secondary: #888888;
--border: 2px solid rgba(255, 60, 60, 0.7);
--border-radius: 12px;
```

字体：系统默认，确保中文显示正常（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`）

## 七、交互细节与边界情况

### 7.1 中文输入法筛选

分类页筛选框必须处理 IME 输入法合成过程：
- `compositionstart` → 设置 `isComposing = true`
- `compositionend` → 设置 `isComposing = false`，立即触发过滤
- `input` 事件 → 仅在 `!isComposing` 时触发过滤

### 7.2 网格点击高亮

- 点击有颜色的格子 → 同色格子全部显示 `outline: 2px solid #ffffff`，其余格子降低透明度（`opacity: 0.3`）
- 材料清单中对应行 → 背景高亮 + 滚动到可视区域（`scrollIntoView`）
- 再次点击同格 或 点击空白格 → 取消所有高亮

### 7.3 空状态

- 分类页搜索无结果：显示"没有找到相关物品"提示
- 图片加载失败：显示占位符（灰色方块 + 物品首字母）

### 7.4 性能

- 分类页物品列表超过 100 项（如 Decorations 517 项）时，使用虚拟滚动或懒加载，避免一次渲染过多 DOM
- 图片使用 `loading="lazy"` 属性

### 7.5 Tab 拖拽滚动（清单汇总页）

PC 端支持鼠标拖拽 Tab 栏横向滚动：

```js
// mousedown → 记录起始位置
// mousemove → 更新 scrollLeft
// mouseup / mouseleave → 结束拖拽
```
